# 最终视频布局规格

## 1. 输出画面基础规格

| 项目 | 规格 |
| --- | --- |
| 输出比例 | 16:9 |
| 推荐基准尺寸 | 1920 x 1080 |
| 输出形式 | MP4 |
| 交互能力 | 无 |
| 布局策略 | 固定布局 + 有限显示模式 |
| 时间基准 | 主课程视频时间 |

最终视频画面只包含主课程视频和课程 HUD。不得包含编辑器工具栏、播放器控件、进度拖动条、时间滑块或可点击提示。

## 2. 推荐画面结构

基于 1920 x 1080 设计基准，推荐将画面分为四层：

1. 背景层：深色科技底板和主视频承载区域。
2. 主内容层：MainVideoFrame。
3. HUD 信息层：顶部栏、右侧栏、底部栏、讲师小窗。
4. 事件反馈层：短时提示、能力解锁、阶段完成反馈。

```text
┌────────────────────────────────────────────────────────────────────┐
│ TopHeader  高 72                                                    │
├──────────────────────────────────────────────┬─────────────────────┤
│                                              │ ChapterMap          │
│                                              │ 高 250-300           │
│                                              ├─────────────────────┤
│ MainVideoFrame                               │ TaskTracker         │
│ 约 1392 x 780                                │ 高 220-260           │
│                                              ├─────────────────────┤
│                                              │ WarningPanel        │
│                                              │ 高 220-260           │
├──────────────────────────────────────────────┴─────────────────────┤
│ LecturerMiniCard / BottomStatusHud / CourseStageBar  高 128         │
└────────────────────────────────────────────────────────────────────┘
```

推荐安全边距：

1. 外边距：24 px。
2. 模块间距：12 px。
3. 顶部 HUD 高度：64 至 80 px。
4. 底部 HUD 高度：112 至 144 px。
5. 右侧辅助栏宽度：360 至 420 px。
6. 主视频区域最小可视宽度：画面宽度的 70%。

## 3. 区域规格

### 3.1 主视频区域

| 项目 | 规格 |
| --- | --- |
| 组件 | MainVideoFrame |
| 推荐位置 | x=24, y=92 |
| 推荐尺寸 | 1392 x 780，随右侧栏宽度微调 |
| 信息内容 | 主课程视频 |
| 是否常驻 | 是 |
| 是否随时间变化 | 视频内容随时间播放，布局默认不变 |
| 是否可编辑 | 可编辑适配方式，不可任意拖拽 |
| 设计优先级 | P0 |

设计要求：

1. 默认完整显示主视频，优先使用 contain。
2. 主视频可有轻量金属细边框，但边框不可压缩可读区域。
3. 不在主视频区域上叠加大面积装饰。
4. 允许出现轻量角标或安全区参考样式，但不得影响课程内容阅读。
5. 当用户选择 fill、fit-width、fit-height 时，编辑器应提示裁切或留边风险。

### 3.2 顶部课程信息栏

| 项目 | 规格 |
| --- | --- |
| 组件 | TopHeader |
| 推荐位置 | x=24, y=16 |
| 推荐尺寸 | 1872 x 64 |
| 信息内容 | 课程标题、章节标题、课程编号、当前阶段短名、品牌标识可选 |
| 是否常驻 | 默认常驻，可隐藏 |
| 是否随时间变化 | 标题默认不变，当前阶段短名可随时间变化 |
| 是否可编辑 | 是 |
| 设计优先级 | P0 |

布局建议：

1. 左侧显示课程标题和课程序号。
2. 中间显示章节标题或当前阶段。
3. 右侧显示轻量状态标签，例如 `MISSION LIVE`、`LESSON 03`。
4. 文案超长时优先截断副标题，不压缩主标题到不可读。

禁用项：

1. 不显示播放状态。
2. 不显示播放倍速。
3. 不显示视频时长进度。

### 3.3 讲师小窗

| 项目 | 规格 |
| --- | --- |
| 组件 | LecturerMiniCard |
| 推荐位置 | 默认底部左侧，x=24, y=940 |
| 推荐尺寸 | 260 x 112 |
| 信息内容 | 讲师视频或头像、讲师名称、身份标签 |
| 是否常驻 | 可常驻、可隐藏 |
| 是否随时间变化 | 讲师视频随时间播放，信息默认不变 |
| 是否可编辑 | 是 |
| 设计优先级 | P1 |

位置预设：

1. bottom-left：底部 HUD 左侧，默认推荐。
2. bottom-right：底部 HUD 右侧，适合主视频左侧操作密集时。
3. in-bottom-hud：嵌入底部状态 HUD。
4. hidden：隐藏。

约束：

1. 小窗不得覆盖主视频核心操作区域。
2. 有讲师视频时优先使用 16:9 或 1:1 裁切预设。
3. 无讲师素材时显示头像或身份牌。
4. 讲师区域不能被设计成直播间互动窗口，不显示弹幕、点赞、连麦等元素。

### 3.4 右侧重点提示

| 项目 | 规格 |
| --- | --- |
| 组件 | WarningPanel |
| 推荐位置 | 右侧辅助栏下部 |
| 推荐尺寸 | 360-420 x 220-260 |
| 信息内容 | 提示类型、标题、正文、短状态标签 |
| 是否常驻 | 容器常驻，内容可按事件出现或切换 |
| 是否随时间变化 | 是 |
| 是否可编辑 | 是 |
| 设计优先级 | P0 |

提示类型：

1. key_point：重点内容。
2. beginner_tip：新手重点。
3. warning：警告或避坑。
4. summary：阶段总结。
5. homework：作业或行动提醒。

显示规则：

1. 单条标题建议 12 字以内。
2. 正文建议 32 字以内，最多 2 到 3 行。
3. 警告类可使用琥珀或红色边缘提示，但不得全屏闪烁。
4. 提示出现时可有 180 至 240 ms 淡入和轻微位移。
5. 同一时间多条提示冲突时，只显示优先级最高的提示。

### 3.5 右侧任务追踪

| 项目 | 规格 |
| --- | --- |
| 组件 | TaskTracker |
| 推荐位置 | 右侧辅助栏中部 |
| 推荐尺寸 | 360-420 x 220-260 |
| 信息内容 | 当前任务、已完成任务、下一任务 |
| 是否常驻 | 默认常驻 |
| 是否随时间变化 | 是 |
| 是否可编辑 | 是 |
| 设计优先级 | P0 |

任务状态：

1. 未开始：低亮度线框。
2. 当前：蓝紫高亮、左侧状态条或扫描线。
3. 已完成：绿色或青色完成标记。

显示规则：

1. 当前任务必须最突出。
2. 默认显示 3 到 5 条任务。
3. 超过 5 条时只显示当前任务附近任务，不做滚动列表效果。
4. 新任务切换时，上一个当前任务默认变为已完成，除非事件另行配置。

### 3.6 右侧课程地图

| 项目 | 规格 |
| --- | --- |
| 组件 | ChapterMap |
| 推荐位置 | 右侧辅助栏上部 |
| 推荐尺寸 | 360-420 x 250-300 |
| 信息内容 | 地图节点、连接线、节点状态、当前节点标签 |
| 是否常驻 | 默认常驻 |
| 是否随时间变化 | 是 |
| 是否可编辑 | 是 |
| 设计优先级 | P0 |

地图形态：

1. 第一版使用纵向节点路线图，不做复杂地图自由绘制。
2. 每个节点对应课程阶段或关键能力点。
3. 节点之间用细线连接，当前节点使用能量光圈或亮边框。
4. 已完成节点使用小型完成标记。

状态：

1. locked：锁定。
2. not_started：未开始。
3. current：当前。
4. completed：已完成。
5. unlocked：已解锁。

### 3.7 底部课程阶段条

| 项目 | 规格 |
| --- | --- |
| 组件 | CourseStageBar |
| 推荐位置 | 底部中部或底部全宽 |
| 推荐尺寸 | x=300, y=956, w=1280-1380, h=84 |
| 信息内容 | 阶段名称、短名、完成状态、当前阶段 |
| 是否常驻 | 默认常驻 |
| 是否随时间变化 | 是 |
| 是否可编辑 | 是 |
| 设计优先级 | P0 |

关键定义：

1. 阶段条是学习导航，不是播放器进度条。
2. 最终视频中不可点击、不可拖动、无滑块。
3. 不显示播放头、时间轴拖柄、播放按钮或总时长。
4. 当前阶段以段块高亮表达，不以播放器式进度填充表达。

显示模式：

1. standard：显示阶段短名、状态和连接线，推荐 3 至 8 个阶段。
2. compact：显示节点和短名，适合 8 个以上阶段。
3. hidden：隐藏，非默认，仅用于主视频底部信息密集场景。

### 3.8 底部状态 HUD

| 项目 | 规格 |
| --- | --- |
| 组件 | BottomStatusHud |
| 推荐位置 | 底部区域，与讲师卡和阶段条协同 |
| 推荐尺寸 | 视布局模式而定，建议高 44-64 |
| 信息内容 | 当前阶段状态、能力点解锁、阶段完成、作业提醒短文案 |
| 是否常驻 | 容器可常驻，事件内容短时出现 |
| 是否随时间变化 | 是 |
| 是否可编辑 | 是 |
| 设计优先级 | P1 |

表现规则：

1. 能力点解锁显示 3 至 5 秒。
2. 阶段完成提示显示 4 至 6 秒。
3. 作业提醒可与 WarningPanel 同步，但底部只显示一句行动短语。
4. 不显示播放时间和视频进度。

## 4. 视觉层级优先级

| 优先级 | 模块 | 说明 |
| --- | --- | --- |
| 1 | MainVideoFrame | 学员主要观看内容 |
| 2 | CourseStageBar | 课程结构定位 |
| 3 | TaskTracker | 当前行动目标 |
| 4 | WarningPanel | 当前重点和提醒 |
| 5 | ChapterMap | 学习路径和完成感 |
| 6 | TopHeader | 上下文信息 |
| 7 | BottomStatusHud | 短时状态反馈 |
| 8 | LecturerMiniCard | 讲师存在感 |

## 5. 最终视频禁用清单

最终 MP4 中不得出现：

1. 播放按钮。
2. 暂停按钮。
3. 可拖动进度条。
4. 播放头滑块。
5. 音量按钮。
6. 倍速按钮。
7. 全屏按钮。
8. 时间拖动控件。
9. 编辑器选中框。
10. 属性面板或时间轴表格。
