# 本地可视化编辑器架构规格

## 1. 编辑器定位

编辑器是课程创作者配置最终视频 HUD 的本地可视化工作台。

它不是：

1. 普通剪辑软件。
2. 网页播放器。
3. 课程平台后台。
4. 自由画布设计器。

它的核心职责是：让用户通过可视化预览、属性面板和时间轴配置，生成一份可被 Remotion 渲染器读取的 `LessonProjectConfig`。

## 2. 编辑器总体结构

```text
┌─────────────────────────────────────────────────────────────────────┐
│ 顶部工具栏：项目名 / 素材状态 / 保存配置 / 校验 / 预览 / 渲染         │
├───────────────┬─────────────────────────────────────┬───────────────┤
│ 素材选择区     │ 中央最终视频预览区                    │ 右侧属性面板    │
│ 主视频         │ 16:9 最终视频画框                      │ 当前选中模块    │
│ 讲师视频/头像  │ 可点击 HUD 模块                        │ 字段与开关      │
│ HUD 静态资源   │ 画框外播放器控件                        │ 时间与绑定      │
├───────────────┴─────────────────────────────────────┴───────────────┤
│ 底部时间轴配置区：阶段视图 / 事件视图 / 校验视图 / 使用当前时间       │
└─────────────────────────────────────────────────────────────────────┘
```

推荐桌面端优先，基准工作区不小于 1440 x 900。

## 3. 编辑器核心模块

### 3.1 顶部工具栏

职责：

1. 显示项目名称。
2. 显示保存状态。
3. 显示主视频导入状态。
4. 显示配置校验状态。
5. 提供保存配置入口。
6. 提供导入和导出配置入口，P1。
7. 提供预览入口。
8. 提供渲染入口。

操作规则：

1. 保存只保存 JSON 配置，不渲染视频。
2. 预览只驱动编辑器当前时间和 HUD 状态。
3. 渲染必须先经过配置校验和素材检查。
4. 主视频缺失、课程标题缺失、阶段为空或关键时间冲突时，渲染入口应阻断。

顶部工具栏不进入最终 MP4。

### 3.2 素材选择区

职责：

1. 选择主课程视频。
2. 选择讲师小窗视频。
3. 选择讲师头像。
4. 选择 HUD 静态资源或 logo，P1。
5. 展示素材状态、时长、分辨率和缺失信息。

素材规则：

1. 主视频必需。
2. 讲师视频和头像可选。
3. 讲师模块可隐藏。
4. 替换主视频时必须提示用户：已有时间点可能需要复查。

素材选择区只修改 `media` 和部分 `lecturer` 配置。

### 3.3 中央最终视频预览区

中央区域包含两层：

1. 16:9 最终视频画框。
2. 画框外编辑器播放器控件。

画框内显示最终 MP4 会包含的内容：

1. MainVideoFrame。
2. TopHeader。
3. ChapterMap。
4. TaskTracker。
5. WarningPanel。
6. CourseStageBar。
7. BottomStatusHud。
8. LecturerMiniCard。

画框外显示编辑器控件：

1. 播放。
2. 暂停。
3. 拖动预览进度。
4. 当前时间。
5. 使用当前时间。
6. 预览缩放。

画框外控件绝不进入最终 MP4。

### 3.4 右侧属性编辑面板

职责：

1. 编辑当前选中的 HUD 模块。
2. 编辑当前选中的阶段。
3. 编辑当前选中的事件。
4. 编辑布局开关。
5. 展示字段级校验错误。

面板结构建议：

1. 标题区：当前选中对象名称。
2. 基础字段区：标题、名称、正文、标签。
3. 素材字段区：视频、头像、静态资源引用。
4. 布局字段区：显示模式、位置预设、可见性。
5. 时间字段区：开始时间、结束时间、持续时间、使用当前时间。
6. 绑定字段区：阶段、地图节点、任务、提示、能力点。
7. 高级字段区：优先级、动效、启用状态。

未选中任何模块时，右侧面板显示项目概览和渲染前待修正项。

### 3.5 底部时间轴配置区

底部区域不做复杂多轨剪辑线，第一版采用：

1. 阶段视图。
2. 事件视图。
3. 校验视图。

阶段视图编辑 `CourseStage`：

1. 阶段名称。
2. 短名称。
3. 开始时间。
4. 结束时间。
5. 关联地图节点。
6. 默认任务。
7. 默认重点提示。
8. 显示顺序。

事件视图编辑 `TimelineEvent`：

1. 启用状态。
2. 事件类型。
3. 触发时间。
4. 结束时间或持续时间。
5. 目标组件。
6. 标题和正文。
7. 关联对象。
8. 动效。
9. 优先级。

校验视图展示：

1. 阶段时间重叠。
2. 提示事件缺少持续时间。
3. 关联 ID 不存在。
4. 同模块同时间同优先级冲突。
5. 主视频缺失。
6. 提示正文过长。

## 4. 模块点选编辑流程

用户点击中央预览画框内的 HUD 模块时，编辑器应执行：

1. 根据点击区域识别 `selectedTarget`。
2. 在画框内显示编辑器选中框。
3. 右侧属性面板切换到对应配置表单。
4. 底部时间轴区筛选或高亮相关阶段和事件。
5. 若当前时间命中该模块事件，面板显示当前生效事件。
6. 用户修改字段后，更新 `LessonProjectConfig`。
7. 重新执行 `resolveHudState(config, currentTime)`。
8. 中央预览即时更新。

点击映射：

| 点击区域 | selectedTarget | 右侧面板 |
| --- | --- | --- |
| TopHeader | `course_metadata` | 课程信息配置 |
| MainVideoFrame | `main_video_frame` | 主视频素材、适配方式、安全区 |
| LecturerMiniCard | `lecturer_mini_card` | 讲师素材、姓名、身份、位置 |
| ChapterMap | `chapter_map` | 地图节点、阶段绑定、节点状态 |
| TaskTracker | `task_tracker` | 任务列表、任务状态规则 |
| WarningPanel | `warning_panel` | 提示内容、类型、时间、优先级 |
| CourseStageBar | `course_stage_bar` | 阶段列表、短名、时间点、显示模式 |
| BottomStatusHud | `bottom_status_hud` | 能力点、阶段完成、作业提醒 |

选中框、悬浮模块名和参考线只属于编辑器，不进入最终视频。

## 5. 编辑器状态模型

建议编辑器维护以下本地状态：

```ts
type EditorState = {
  config: LessonProjectConfig;
  currentTime: number;
  isPlaying: boolean;
  selectedTarget?: EditorSelection;
  activeTimelineView: "stages" | "events" | "validation";
  validationIssues: ValidationIssue[];
  saveStatus: "saved" | "dirty" | "saving" | "error";
  previewZoom: number;
};
```

说明：

1. `config` 是唯一可保存的项目数据。
2. `currentTime` 只属于编辑器预览，不直接保存为最终视频状态。
3. `selectedTarget` 是编辑器 UI 状态，不进入渲染器。
4. `validationIssues` 可由 schema 校验和业务校验生成。

## 6. 预览状态计算

每当以下情况发生时，编辑器应重新计算预览状态：

1. 当前视频时间变化。
2. 阶段配置变化。
3. 事件配置变化。
4. 任务、地图、提示或能力点变化。
5. 布局显示模式变化。
6. 素材引用变化。

计算流程：

```text
LessonProjectConfig + currentTime
        │
        ├── validate basic shape
        ├── resolve current stage
        ├── apply default stage links
        ├── apply timeline events
        └── HudRuntimeState
```

中央预览组件接收 `HudRuntimeState` 和 `layout` 后渲染当前时间点画面。

## 7. 使用当前时间

编辑器必须支持“使用当前时间”。

写入规则：

| 当前编辑对象 | 写入字段 |
| --- | --- |
| 阶段开始时间 | `CourseStage.startTime` |
| 阶段结束时间 | `CourseStage.endTime` |
| 事件触发时间 | `TimelineEvent.startTime` |
| 提示结束时间 | `TimelineEvent.endTime` |
| 地图节点解锁时间 | `MapNode.unlockTime` |

写入后：

1. 立即标记配置为 dirty。
2. 立即重新计算 HUD 状态。
3. 若产生时间冲突，在字段旁展示错误。

## 8. 保存配置

保存操作应保存：

1. 项目信息。
2. 课程信息。
3. 讲师信息。
4. 素材引用。
5. 布局配置。
6. 主题配置。
7. 阶段、任务、地图、提示、能力点。
8. 时间轴事件。
9. 渲染配置。

保存前流程：

1. 执行 Zod schema 校验。
2. 执行业务校验。
3. 若存在阻断错误，提示用户。
4. 若只有非阻断警告，可允许保存但继续提示。

## 9. 导出配置

导出配置用于：

1. 备份项目。
2. 复用课程模板。
3. 给高级用户或后续批量渲染使用。

导出文件建议为 JSON。

导出不包含大视频文件本体，只包含素材路径引用。

## 10. 触发渲染

用户点击渲染时，编辑器不应直接跳过检查。

推荐流程：

1. 保存当前配置。
2. 执行配置校验。
3. 执行素材路径检查。
4. 展示渲染前检查清单。
5. 用户确认后调用 Node 渲染脚本。
6. 展示渲染中状态。
7. 渲染完成后显示输出路径。
8. 渲染失败时显示错误摘要和日志路径。

阻断项：

1. 主视频缺失。
2. 课程标题为空。
3. 阶段为空。
4. 阶段时间倒置或严重重叠。
5. 提示类事件缺少结束时间或持续时间。
6. 引用的素材或对象不存在。

## 11. 编辑器与渲染器接口

编辑器传给渲染器的唯一核心输入应是：

1. 配置文件路径。
2. 可选输出路径。
3. 可选渲染质量参数。

不应传递：

1. 当前选中模块。
2. 属性面板状态。
3. 编辑器播放器控件状态。
4. 选中框和参考线。
5. 时间轴表格 UI 状态。

## 12. 编辑器验收标准

后续实现完成后应满足：

1. 用户可以导入主视频并读取当前时间。
2. 用户可以点击 HUD 模块并在右侧编辑字段。
3. 用户可以配置阶段和 7 类时间轴事件。
4. 用户可以使用当前时间写入时间字段。
5. 预览画面能按当前时间显示 HUD 状态。
6. 保存出的配置可被 Remotion 渲染器读取。
7. 编辑器播放器控件不进入最终视频画框。
