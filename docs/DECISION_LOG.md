# 产品决策记录

## 1. 已确定的关键产品决策

### D001：产品定位为时间轴驱动的课程界面渲染器

决策：

《视频课程套壳》不是普通剪辑软件、课程平台、播放器或静态遮罩模板。它的核心是根据主课程视频时间轴，同步渲染课程 HUD 界面。

理由：

目标用户的核心痛点不是缺少剪辑工具，而是缺少一种低成本方式把普通课程视频包装成结构清晰、任务推进、带学习导航的成片。

影响：

1. 第一版必须支持时间点配置。
2. 所有核心模块都应围绕时间轴变化设计。
3. 功能优先级应高于普通剪辑能力。

### D002：第一版采用手动配置时间点

决策：

第一版不做 AI 自动识别章节、重点、任务或时间点。用户手动配置阶段和事件时间。

理由：

手动配置更可控，工程风险更低，更适合快速验证产品核心价值。

影响：

1. 编辑器必须提供播放器预览和当前时间读取。
2. 必须提供“使用当前时间”能力。
3. 时间轴配置区是 P0。

### D003：第一版必须有可视化编辑器

决策：

第一版不能只依赖手写 JSON。用户必须能在可视化预览中看到 HUD 布局，并通过右侧属性面板编辑模块内容。

理由：

目标用户多为课程创作者和小型后期人员，不应要求他们理解配置文件结构才能使用产品。

影响：

1. 中央预览区是 P0。
2. 模块点选和属性面板是 P0。
3. JSON 配置可作为导入导出能力，但不能是主操作路径。

### D004：最终视频中不能出现播放器控件

决策：

编辑器中可以有播放、暂停、拖动、当前时间等控件，用于配置时间点。最终导出的 MP4 中不能出现任何播放器控件。

理由：

最终输出是视频文件，不是播放器产品。播放器控件会混淆底部课程阶段条的定位，也会破坏成片专业度。

影响：

1. 编辑器 UI 与最终视频画面必须清晰分离。
2. 渲染区域只能包含课程画面和 HUD。
3. 底部阶段条必须设计成学习导航，而非播放进度条。

### D005：底部课程阶段条是学习导航，不是播放器进度条

决策：

第一版底部必须支持课程阶段条，用于显示已完成、当前、未开始的课程阶段。

理由：

课程阶段条帮助学员快速判断当前处于课程结构中的哪个位置，是课程理解和完播引导的核心组件。

影响：

1. 阶段条在编辑器中可点击跳转预览。
2. 阶段条在最终视频中不可点击。
3. 阶段条应与课程地图、任务追踪联动。

### D006：主视频内容永远第一优先级

决策：

所有 HUD 设计必须服从主课程视频可读性。默认完整显示主视频，避免裁切和遮挡关键内容。

理由：

用户购买或观看的是课程内容，不是 HUD。HUD 的价值是增强理解，而不是替代课程本身。

影响：

1. 主视频区域必须占据最大视觉权重。
2. 右侧栏、底部栏、讲师小窗都要有安全区域意识。
3. 渲染前检查需要提示遮挡风险。

### D007：第一版采用固定布局和有限配置

决策：

第一版不做自由拖拽和任意排版。采用固定布局、模块点选、属性编辑、少量布局开关和位置预设。

理由：

自由设计会显著增加编辑器复杂度、渲染复杂度和用户学习成本。第一版需要优先验证时间轴 HUD 渲染价值。

影响：

1. UI Agent 需要设计稳定默认布局。
2. 前端 Agent 实现有限布局配置即可。
3. Remotion Agent 可基于稳定模块结构实现渲染。

### D008：右侧辅助栏承载地图、任务和重点提示

决策：

右侧辅助栏作为课程 HUD 的主要信息承载区，默认包含课程地图、任务追踪和重点提示。

理由：

右侧栏能将辅助信息与主视频主体区分开，降低遮挡主视频的风险，同时形成游戏化课程界面感。

影响：

1. 右侧栏是 P0 模块。
2. 内部模块需要支持随时间变化。
3. 可提供显示模式，但默认完整显示。

### D009：讲师小窗是 P1，不是核心阻断项

决策：

第一版支持讲师小窗视频或头像，但其优先级低于主视频、阶段条、地图、任务和重点提示。

理由：

讲师存在感重要，但产品的核心验证点是时间轴驱动 HUD，而不是讲师视频合成。

影响：

1. 无讲师视频时可以使用头像或隐藏。
2. 讲师小窗位置只支持有限预设。
3. 不应为了讲师小窗牺牲主视频可读性。

### D010：第一版输出以 16:9 MP4 为主

决策：

第一版聚焦 16:9 MP4 输出。

理由：

课程录屏和教程视频多数以横屏为主，16:9 能最大化适配主课程视频和平台上传需求。

影响：

1. 暂不优先支持竖屏和方形视频。
2. 布局设计以横屏课程观看体验为准。

## 2. MVP 功能冻结摘要

P0 功能：

1. 主视频导入与预览。
2. 课程基础信息。
3. 固定最终视频 HUD 布局。
4. 底部课程阶段条。
5. 课程地图。
6. 任务追踪。
7. 重点提示。
8. 手动时间轴事件配置。
9. 可视化预览。
10. 右侧属性面板。
11. “使用当前时间”。
12. 渲染导出 16:9 MP4。
13. 最终视频无播放器控件。

P1 功能：

1. 讲师小窗或头像。
2. 讲师小窗位置预设。
3. 能力点解锁。
4. 阶段总结。
5. 作业提醒。
6. 基础主题预设。
7. 项目配置保存。
8. 渲染前检查。

P2 功能：

1. AI 自动章节识别。
2. AI 自动生成提示和任务。
3. 自定义网页播放器。
4. 最终播放器中的可点击章节。
5. 自由布局设计。
6. 批量渲染。
7. 课程平台能力。

## 3. 仍需确认的问题

### Q001：第一版是否必须保存项目配置文件

当前建议：

项目配置保存为 P1。如果工程成本可控，应支持保存和再次编辑，否则会影响用户修正和复用。

待确认：

1. 是否必须在 MVP 首次交付中支持保存项目。
2. 配置文件是否需要用户可导入导出。

### Q002：第一版渲染是在本地还是服务端

当前建议：

产品层不限定实现方式，但必须保证用户能获得最终 16:9 MP4。

待确认：

1. 本地渲染还是云端渲染。
2. 渲染耗时如何提示。
3. 渲染失败如何恢复。

### Q003：主题预设数量

当前建议：

第一版只需要 1 套默认主题，最多提供少量主题预设。不要把主题系统做成核心复杂功能。

待确认：

1. 是否需要多主题。
2. 是否需要品牌色配置。
3. 是否需要上传 logo。

### Q004：讲师小窗是否必须支持视频

当前建议：

讲师小窗视频作为 P1。如果工期有限，头像优先，小窗视频后置。

待确认：

1. 是否必须支持讲师视频。
2. 讲师视频是否需要与主视频同步。
3. 如果讲师视频时长与主视频不同，如何处理。

### Q005：提示类事件的动画复杂度

当前建议：

第一版采用简单出现、消失和高亮，不做复杂动画。

待确认：

1. 是否需要入场和退场动画。
2. 是否需要不同提示类型对应不同动画。
3. 是否允许提示堆叠。

### Q006：阶段条最大支持多少阶段

当前建议：

第一版建议支持 3 到 8 个阶段。超过 8 个时需要紧凑模式或滚动策略，但最终视频中不应出现可交互滚动。

待确认：

1. 阶段数量上限。
2. 名称过长时的截断规则。
3. 紧凑模式默认展示字段。

### Q007：主视频安全区域如何判断

当前建议：

第一版先通过布局默认值和人工预览解决，不做自动识别遮挡。

待确认：

1. 是否需要安全区域参考线。
2. 是否需要渲染前遮挡检查提示。
3. 是否允许用户选择主视频适配策略。

### Q008：是否需要字幕能力

当前建议：

字幕不进入 MVP P0。字幕可能与底部阶段条和 HUD 产生布局冲突，后续单独设计。

待确认：

1. 是否已有主视频字幕。
2. 是否需要导入字幕文件。
3. 字幕与底部 HUD 如何避让。

### Q009：配置数据是否需要公开给高级用户

当前建议：

主路径是可视化编辑。配置文件导入导出可作为 P1 或 P2，方便高级用户和批量制作。

待确认：

1. 是否需要导出 JSON。
2. 是否需要手动编辑 JSON。
3. 是否需要配置校验错误提示。

### Q010：成片是否需要带水印或品牌标识

当前建议：

产品层暂不强制。若需要品牌标识，应作为可配置 HUD 元素，不能遮挡主视频。

待确认：

1. 是否需要课程品牌 logo。
2. 是否需要工具水印。
3. 水印是否可关闭。

## 4. 后续 Agent 交接说明

### 4.1 给 UI Agent

需要基于以下冻结点设计：

1. 主视频内容优先。
2. 16:9 横屏最终视频布局。
3. 顶部课程信息栏。
4. 右侧辅助栏：地图、任务、重点提示。
5. 底部课程阶段条：学习导航，不是进度条。
6. 讲师小窗有限位置预设。
7. 编辑器布局：顶部工具栏、素材区、中央预览、右侧属性面板、底部时间轴配置区。
8. 最终视频无播放器控件。

### 4.2 给前端 Agent

需要基于以下冻结点实现：

1. 可视化预览。
2. 模块点选。
3. 右侧属性面板。
4. 表格式或列表式时间轴配置。
5. 当前时间读取。
6. 使用当前时间写入阶段或事件。
7. 点击阶段、地图节点、事件跳转预览。
8. 编辑器控件不进入最终渲染画面。

### 4.3 给 Remotion 渲染 Agent

需要基于以下冻结点实现：

1. 以主视频时间为时间轴基准。
2. 根据 CourseStage 计算当前阶段状态。
3. 根据 TimelineEvent 计算 HUD 状态。
4. 渲染顶部栏、右侧栏、地图、任务、重点提示、底部阶段条、讲师小窗。
5. 输出 16:9 MP4。
6. 不渲染编辑器播放器控件。
7. 保证主视频内容优先，HUD 不喧宾夺主。
