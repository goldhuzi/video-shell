# 用户工作流

## 1. 总体流程

用户从素材准备到成片检查的完整流程如下：

1. 准备素材。
2. 打开编辑器。
3. 导入主课程视频。
4. 配置课程基础信息。
5. 配置最终视频界面布局。
6. 配置课程阶段。
7. 配置时间轴事件。
8. 预览不同时间点的界面状态。
9. 执行渲染。
10. 检查最终成片。
11. 保存项目配置或继续修正。

## 2. 阶段一：准备素材

### 2.1 用户准备内容

用户在进入编辑器前，建议准备：

1. 主课程视频。
2. 讲师小窗视频或头像。
3. 课程标题。
4. 章节名称。
5. 讲师名称和身份。
6. 课程阶段列表。
7. 每个阶段的大致开始时间。
8. 当前课程的任务列表。
9. 重点提示、避坑提示、阶段总结和作业提醒文案。
10. 课程地图节点名称。

### 2.2 素材原则

1. 主课程视频是第一优先级。
2. 主视频中有操作演示时，HUD 不应遮挡关键按钮、菜单、代码区或演示主体。
3. 讲师小窗不是必需项；没有讲师视频时可以使用头像或隐藏。
4. 重点提示文案应短，不应占用过多画面空间。

## 3. 阶段二：打开编辑器并创建项目

### 3.1 创建项目

用户进入编辑器后：

1. 新建项目。
2. 设置项目名称。
3. 选择输出比例，第一版固定为 16:9。
4. 进入编辑主界面。

### 3.2 编辑器主界面结构

编辑器默认包含：

1. 顶部工具栏。
2. 左侧或顶部素材入口。
3. 中央实时预览区。
4. 右侧属性面板。
5. 底部时间轴配置区。
6. 渲染导出入口。

编辑器中的播放器控件只用于预览和配置时间点，不会出现在最终视频中。

## 4. 阶段三：导入主课程视频

### 4.1 导入操作

用户上传或选择主课程视频后，系统：

1. 读取视频时长。
2. 在中央预览区显示主视频。
3. 显示当前播放时间。
4. 允许播放、暂停和拖动预览。

### 4.2 主视频适配

用户可选择主视频适配方式：

1. 完整显示，默认选项。
2. 填充显示。
3. 适配宽度。
4. 适配高度。

默认采用完整显示，以保护主课程内容不被裁切。

## 5. 阶段四：配置课程基础信息

### 5.1 配置入口

用户可以：

1. 点击预览画面中的顶部课程信息栏。
2. 在右侧属性面板编辑课程信息。

### 5.2 可配置字段

1. 课程标题。
2. 章节标题或副标题。
3. 课程编号。
4. 讲师名称。
5. 讲师身份。
6. 主题预设。

### 5.3 即时反馈

用户修改字段后，中央预览画面应立即更新对应文案。

## 6. 阶段五：配置界面布局

### 6.1 固定布局基础

第一版采用固定布局，不提供自由拖拽画布。

用户可以通过有限开关调整：

1. 讲师小窗位置。
2. 右侧辅助栏显示模式。
3. 底部阶段条显示模式。
4. 顶部课程信息栏显示状态。
5. 主视频适配方式。

### 6.2 模块点选编辑

用户在预览画面中点击模块后，右侧属性面板切换为对应模块配置：

1. 点击顶部栏：编辑课程信息。
2. 点击讲师小窗：编辑讲师视频、头像、名称、位置。
3. 点击右侧任务追踪：编辑任务列表和当前任务状态。
4. 点击课程地图：编辑地图节点。
5. 点击重点提示：编辑提示类型和文案。
6. 点击底部阶段条：编辑阶段名称、时间点和状态。

### 6.3 布局检查

编辑器应帮助用户确认：

1. 主视频关键内容没有被遮挡。
2. 右侧辅助栏内容不过长。
3. 底部阶段条不会覆盖课程字幕或操作区域。
4. 讲师小窗位置不影响主视频理解。

## 7. 阶段六：设置课程阶段

### 7.1 阶段配置方式

用户在底部时间轴配置区添加课程阶段。第一版可以采用表格式配置。

每个阶段包含：

1. 阶段名称。
2. 开始时间。
3. 结束时间。
4. 对应地图节点。
5. 对应默认任务。
6. 对应默认重点提示。
7. 底部阶段条显示名称。

### 7.2 使用当前时间

用户可以：

1. 播放或拖动预览视频到目标时间。
2. 点击“使用当前时间”。
3. 系统把当前时间写入选中阶段的开始时间或结束时间。

### 7.3 阶段跳转

在编辑器中，用户点击某个阶段后，预览视频跳转到该阶段开始时间。

注意：此能力只存在于编辑器中。最终导出的 MP4 中，底部阶段条不可点击。

## 8. 阶段七：配置时间轴事件

### 8.1 事件添加

用户在时间轴配置区添加事件，并选择事件类型：

1. 地图节点点亮。
2. 重点提示弹出。
3. 任务状态切换。
4. 底部阶段条变化。
5. 能力点解锁。
6. 阶段总结。
7. 作业提醒。

### 8.2 事件字段

每个事件至少配置：

1. 触发时间。
2. 事件类型。
3. 目标模块。
4. 标题。
5. 正文文案。
6. 持续时间或结束时间，提示类事件必填。
7. 优先级，处理同一时间多个事件的显示冲突。

### 8.3 事件预览

用户选择某个事件后：

1. 预览视频跳转到事件触发时间。
2. 预览画面显示该事件发生后的 HUD 状态。
3. 右侧属性面板显示该事件的可编辑字段。

## 9. 阶段八：预览

### 9.1 时间点预览

用户可以在编辑器中：

1. 播放整条视频预览 HUD 变化。
2. 点击阶段条跳转到阶段开始时间。
3. 点击地图节点跳转到对应时间。
4. 点击事件列表跳转到事件触发时间。

### 9.2 预览检查重点

用户应检查：

1. 阶段条是否在正确时间高亮。
2. 课程地图节点是否同步点亮。
3. 当前任务是否准确切换。
4. 重点提示是否出现在合适位置。
5. 提示持续时间是否足够阅读。
6. HUD 是否遮挡主视频关键内容。
7. 讲师小窗是否影响观看。

## 10. 阶段九：渲染

### 10.1 渲染前检查

渲染前，系统应提示用户确认：

1. 主视频已导入。
2. 课程标题已填写。
3. 至少有一个课程阶段。
4. 阶段时间不重叠或顺序异常。
5. 关键时间轴事件已配置。
6. 最终视频中不会出现播放器控件。

### 10.2 渲染输出

用户点击渲染后，系统生成 16:9 MP4。

输出视频包含主视频和同步变化的 HUD 界面。播放、暂停、拖动、倍速、音量、全屏等控件不会被渲染进最终视频。

## 11. 阶段十：检查成片

### 11.1 成片检查项

用户检查最终 MP4：

1. 主课程视频是否完整清晰。
2. 课程标题和讲师信息是否正确。
3. 阶段条是否按时间推进。
4. 地图节点是否正确点亮。
5. 任务切换是否准确。
6. 重点提示是否易读且不过长。
7. 阶段总结和作业提醒是否出现。
8. 画面中是否没有播放器控件。
9. HUD 是否未遮挡主视频关键内容。

### 11.2 修改与再渲染

如发现问题，用户返回编辑器：

1. 调整文案。
2. 调整时间点。
3. 调整布局预设。
4. 重新预览。
5. 再次渲染。

## 12. 推荐首版用户路径

首版应优先优化这条最短路径：

1. 上传主课程视频。
2. 填写课程标题和讲师信息。
3. 添加 5 个课程阶段。
4. 用“使用当前时间”设置阶段开始时间。
5. 为每个阶段配置一个任务和一个重点提示。
6. 配置地图节点随阶段点亮。
7. 预览整条视频。
8. 渲染导出 MP4。
