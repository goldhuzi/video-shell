1. 讲师视频素材只有约 9.7 秒，无法验证完整课程讲师小窗视频链路。
   - 当前处理：从讲师视频首帧派生头像，使用 `speaker.displayMode = "avatar"` 和 `audio.mode = "main-only"`。
   - 后续建议：提供与主课程同长度或可循环策略明确的讲师视频，再单独验收 `speakerVideo`。

   - 当前处理：按 0、92、176、300、450 秒拆为 5 个阶段。
   - 后续建议：由课程主理人复核阶段切点、提示文案、作业提醒是否符合课程意图。

3. `npm run test:hud` 仍硬编码测试原 `lesson-01.json` 的关键点，不能直接覆盖 `lesson-01.sample.json`。
   - 当前处理：用 `render:still` 和 `render:clip` 覆盖真实样片关键事件。
   - 后续建议：增加按 lesson id 和时间点输入的 HUD 状态测试脚本。
