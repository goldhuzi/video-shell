# 《视频课程套壳》项目产品定义

## 1. 产品定位

《视频课程套壳》是一款面向课程创作者的视频课程 HUD 渲染工具。

它的核心不是剪辑、播放或课程托管，而是：在主课程视频之上，根据用户手动配置的时间轴事件，同步渲染一套游戏化课程界面。

用户提供主课程视频、讲师小窗视频或头像、课程信息、阶段信息、任务信息、重点提示、地图节点等内容。系统通过可视化编辑器帮助用户配置这些信息在不同视频时间点的展示状态，并最终渲染生成一条 16:9 MP4 成片。

产品核心定义：

> 一个时间轴驱动的课程界面渲染器。

第一版必须支持手动配置时间点，让界面内容随视频进度变化。最终输出视频中只包含渲染后的画面内容，不出现播放、暂停、拖动、倍速等播放器控件。

## 2. 目标用户

### 2.1 首要用户

1. OPC 和一人公司
   - 独立制作课程、训练营、教程或知识产品。
   - 需要快速把普通录屏包装成更有结构感和高级感的课程视频。
   - 通常没有完整后期团队，希望工具足够简单。

2. 个人课程主理人
   - 有明确课程 IP、方法论或训练体系。
   - 希望视频成片呈现出路线图、任务推进和能力解锁感。
   - 需要稳定复用同一套课程界面风格。

3. 自媒体课程创作者
   - 面向 B 站、小红书、视频号、抖音、YouTube 等平台输出教学内容。
   - 希望提升完播率和信息密度，让学员更容易跟住讲解节奏。
   - 需要把重点提示、避坑提醒、任务状态做成视频内可视化元素。

4. 小型后期制作人员
   - 为课程客户批量制作教程视频。
   - 希望用配置化方式替代重复手工套模板。
   - 需要稳定、可复用、可交付的渲染配置。

### 2.2 非首要用户

1. 需要复杂剪辑能力的专业剪辑师。
2. 需要课程售卖、学习管理、账号体系的在线教育机构。
3. 只想套一张静态遮罩、不需要时间轴变化的用户。
4. 需要交互式网页播放器或可点击章节播放体验的团队。

## 3. 用户痛点

### 3.1 普通课程视频结构感弱

很多课程视频只有录屏和讲师讲解，学员难以判断当前处于课程的哪个阶段、接下来会讲什么、已经完成了什么。

### 3.2 手工后期制作成本高

如果用传统剪辑软件实现地图点亮、任务切换、重点提示、阶段条变化，需要大量关键帧、图层和手动对齐。对个人创作者来说成本过高。

### 3.3 静态模板无法表达学习进度

普通遮罩模板只能提供固定装饰，不能根据视频时间同步切换任务、阶段、提示和地图状态，无法形成真正的课程导航体验。

### 3.4 课程重点容易被埋没

学员观看长视频时容易错过关键概念、避坑提醒和行动任务。创作者需要一种方式把当前最重要的信息稳定地呈现在画面中。

### 3.5 纯 JSON 配置门槛高

时间轴事件需要精确配置，但目标用户不一定具备工程背景。第一版必须提供可视化编辑器，让用户通过预览画面、属性面板和时间轴配置完成主要操作。

## 4. 核心价值

### 4.1 把普通课程视频变成任务推进式学习视频

通过任务追踪、课程地图、阶段条、重点提示和能力解锁，把单向讲解包装成“正在推进任务”的学习体验。

### 4.2 用时间轴事件替代手工关键帧

用户只需配置时间点和对应内容，系统负责在正确时间渲染对应界面状态，降低后期制作复杂度。

### 4.3 保证主视频内容优先

主课程视频是最终成片的核心。所有 HUD、提示、地图、阶段条和讲师小窗都必须服务于主视频理解，不能遮挡关键课程内容，不能喧宾夺主。

### 4.4 形成可复用课程包装体系

同一套布局、课程信息结构和事件模型可以复用到多节课，帮助个人创作者形成稳定的课程视觉资产。

### 4.5 让非工程用户也能配置动态课程界面

通过可视化预览、点击模块编辑、表格式时间轴和“使用当前时间”能力，降低配置门槛。

## 5. 产品边界

### 5.1 本产品是什么

1. 时间轴驱动的课程界面渲染器。
2. 16:9 课程视频 HUD 包装工具。
3. 支持手动配置时间点的可视化课程视频编辑器。
4. 支持最终渲染 MP4 的课程视频生成工具。
5. 面向课程结构、任务推进和学习导航的界面化工具。

### 5.2 本产品不是什么

1. 不是普通剪辑软件。
   - 不提供多轨剪辑、复杂转场、素材拼接、字幕精剪、音频混音等专业剪辑能力。

2. 不是课程平台。
   - 不提供课程售卖、学员管理、支付、作业批改、学习记录、账号体系。

3. 不是播放器。
   - 最终输出是 MP4 视频，不提供可点击跳转、暂停、倍速、弹幕、互动问答等播放器功能。

4. 不是静态遮罩模板。
   - 第一版核心必须支持随视频时间变化的界面状态。

5. 不是 Figma 式自由设计工具。
   - 第一版采用固定布局、有限布局开关和可视化点选编辑，不做任意拖拽、任意缩放、多层级自由排版。

## 6. 输入与输出

### 6.1 输入

#### 必需输入

1. 主课程视频
   - 作为最终成片的主要内容。
   - 默认 16:9 输出。
   - 主视频内容优先，默认完整显示，避免裁切关键操作区域。

2. 课程基础信息
   - 课程标题。
   - 课程副标题或章节名称。
   - 讲师名称。
   - 课程编号或阶段编号，非必需但建议支持。

3. 课程阶段信息
   - 阶段名称。
   - 阶段开始时间。
   - 阶段结束时间，或由下一个阶段开始时间自动推算。
   - 当前阶段文案。

4. 时间轴事件配置
   - 地图节点点亮。
   - 任务状态变化。
   - 重点提示弹出或切换。
   - 底部阶段条变化。
   - 能力点解锁。
   - 阶段总结。
   - 作业或行动提醒。

#### 可选输入

1. 讲师小窗视频。
2. 讲师头像。
3. 讲师身份标签。
4. 课程地图节点列表。
5. 任务列表。
6. 品牌色或主题预设。
7. 右侧辅助栏显示模式。
8. 底部阶段条显示模式。

### 6.2 输出

#### 第一版核心输出

1. 一条 16:9 MP4 视频。
2. 视频中包含：
   - 主课程视频区域。
   - 顶部课程信息栏。
   - 讲师小窗或头像区域。
   - 右侧辅助栏。
   - 课程地图。
   - 任务追踪。
   - 重点提示。
   - 底部课程阶段条。
   - 底部状态 HUD。
3. 视频中的 HUD 状态根据时间轴事件自动变化。
4. 最终视频中不出现播放器控件。

#### 可选输出

1. 项目配置文件。
2. 渲染配置快照。
3. 预览用低清视频或片段。

## 7. 核心使用场景

### 7.1 将普通录屏包装为游戏化课程视频

用户上传一条屏幕录制课程视频，填写课程标题、阶段名称、任务列表和重点提示。系统根据用户配置的时间点，在成片中显示课程地图推进、任务切换和重点提醒。

### 7.2 制作训练营课程单节视频

用户为一节训练营课程配置“开场目标、知识讲解、操作演示、练习任务、阶段总结、课后作业”等阶段。底部阶段条同步显示学员当前所在阶段，右侧任务栏提示当前任务。

### 7.3 批量制作同一风格的课程系列

创作者先确定一套固定 HUD 布局，再为每节课填写不同课程信息和时间轴事件。系统生成视觉风格一致的系列课程视频。

### 7.4 为知识类自媒体视频增强完播引导

用户把长教程拆成多个模块，用底部课程阶段条显示讲解进度，用重点提示强调关键句，用能力点解锁制造学习完成感。

### 7.5 小型后期人员为客户交付课程包装

后期人员拿到客户主视频和课程大纲后，在编辑器中快速配置时间节点，预览确认无误后渲染交付 MP4。

## 8. 产品战略画布摘要

### 8.1 愿景

让个人课程创作者也能用低成本方式制作结构清晰、任务明确、有学习推进感的高级课程视频。

### 8.2 首要细分市场

第一阶段优先服务“已有课程内容但缺少后期包装能力”的个人课程创作者和 OPC。原因是他们对效率、成片质感和复用性都有强需求，同时不需要复杂平台能力。

### 8.3 成本定位

产品不追求替代专业剪辑套件，而是以低学习成本、低配置成本和稳定渲染结果形成价值。相对专业剪辑软件，牺牲自由度，换取课程 HUD 场景下的效率和一致性。

### 8.4 核心取舍

第一版优先做“固定布局 + 时间轴事件 + 可视化配置 + 稳定渲染”，不做复杂剪辑、自由设计和课程平台。

### 8.5 北极星指标建议

成功渲染的有效课程视频数量。

“有效”定义为：用户完成素材导入、配置至少 3 个阶段和 3 个时间轴事件，并成功导出 MP4。
