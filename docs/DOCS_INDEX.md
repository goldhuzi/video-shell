# 文档索引

本索引按读者分组。第一次接手项目，先读“新人先看”。

## 新人先看

1. `docs/START_HERE.md`：最快理解项目、边界和最短跑通路径。
2. `docs/USER_GUIDE.md`：完整用户手册。
3. `README.md`：项目入口和常用链接。
