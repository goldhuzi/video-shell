# 编辑器布局规格

## 1. 编辑器定位

编辑器是创作者配置最终视频 HUD 的本地可视化工作台，不是普通剪辑软件，也不是播放器产品。

编辑器必须让用户完成：

1. 导入主课程视频和讲师素材。
2. 填写课程基础信息。
3. 在中央预览中看到最终视频画面。
4. 点击预览画面中的 HUD 模块。
5. 在右侧属性面板编辑该模块内容。
6. 在底部配置课程阶段和时间轴事件。
7. 使用当前视频时间写入阶段或事件。
8. 预览 HUD 随时间变化。
9. 执行渲染并导出 MP4。

## 2. 页面整体结构

推荐桌面端工作区采用 1440 x 900 以上尺寸设计，优先适配横屏桌面环境。

```text
┌─────────────────────────────────────────────────────────────────────┐
│ 顶部工具栏：项目名 / 素材状态 / 保存 / 预览 / 渲染                    │
├───────────────┬─────────────────────────────────────┬───────────────┤
│ 素材选择区     │ 中央最终视频预览区                    │ 右侧属性面板    │
│ 主视频         │ 16:9 画框                             │ 当前选中模块    │
│ 讲师视频/头像  │ 可点击 HUD 模块                        │ 字段与开关      │
│ 配置状态       │ 预览播放器控件                         │ 时间与文案      │
├───────────────┴─────────────────────────────────────┴───────────────┤
│ 底部时间轴配置区：阶段 / 事件 / 当前时间 / 使用当前时间 / 校验提示      │
└─────────────────────────────────────────────────────────────────────┘
```

推荐区域尺寸：

| 区域 | 推荐尺寸 | 优先级 |
| --- | --- | --- |
| 顶部工具栏 | 高 56-64 px | P0 |
| 素材选择区 | 宽 240-280 px | P1 |
| 中央预览区 | 剩余主区域，16:9 画框居中 | P0 |
| 右侧属性面板 | 宽 320-380 px | P0 |
| 底部时间轴配置区 | 高 220-280 px | P0 |

## 3. 顶部工具栏

### 3.1 信息内容

顶部工具栏包含：

1. 项目名称。
2. 当前项目保存状态。
3. 主视频导入状态。
4. 配置校验状态。
5. 保存入口。
6. 预览入口。
7. 渲染入口。
8. 导入或导出配置入口，P1。

### 3.2 操作规则

1. 保存按钮用于保存项目配置，不渲染视频。
2. 预览按钮用于播放当前时间轴状态，不导出 MP4。
3. 渲染按钮进入渲染前检查，不应直接跳过校验。
4. 当主视频未导入、课程标题为空、阶段为空或时间冲突时，渲染入口应显示不可用或需修正状态。

### 3.3 与最终视频关系

顶部工具栏只属于编辑器，不进入最终视频。

## 4. 素材选择区

### 4.1 信息内容

素材选择区包含：

1. 主课程视频卡片。
2. 讲师视频卡片。
3. 讲师头像卡片。
4. 素材时长、分辨率、导入状态。
5. 替换素材入口。
6. 素材缺失提示。

### 4.2 操作规则

1. 主课程视频为必需素材。
2. 讲师视频和头像为可选素材，可二选一，也可隐藏讲师模块。
3. 选择主视频后，系统读取视频时长，并同步到底部时间轴。
4. 替换主视频时，应提示可能影响已配置时间点。

### 4.3 可合并策略

如果桌面空间不足，素材选择区可折叠为左侧图标栏或顶部素材按钮，但必须保留清晰素材状态。

## 5. 中央最终视频预览区

### 5.1 预览画框

中央预览区显示一个 16:9 画框，画框内应尽量忠实呈现最终导出视频的视觉结果。

画框内包含：

1. MainVideoFrame。
2. TopHeader。
3. LecturerMiniCard。
4. WarningPanel。
5. TaskTracker。
6. ChapterMap。
7. CourseStageBar。
8. BottomStatusHud。

画框外包含：

1. 播放、暂停按钮。
2. 编辑器预览进度拖动条。
3. 当前时间显示。
4. 使用当前时间按钮。
5. 预览缩放控制。

画框外控件不会进入最终 MP4。

### 5.2 模块点选编辑

用户点击预览画面中的模块时：

1. 被点击模块显示编辑器选中框。
2. 右侧属性面板切换到对应模块配置。
3. 底部时间轴区可同步筛选与该模块相关的事件。
4. 如果模块绑定当前时间事件，属性面板显示当前时间下生效的数据。

模块点击映射：

| 点击区域 | 右侧属性面板打开 |
| --- | --- |
| 顶部课程信息栏 | 课程信息配置 |
| 主视频区域 | 主视频适配与安全区配置 |
| 讲师小窗 | 讲师素材、名称、身份、位置 |
| 课程地图 | 地图节点列表与绑定阶段 |
| 任务追踪 | 任务列表与状态规则 |
| 重点提示 | 提示内容、类型、持续时间 |
| 底部阶段条 | 阶段名称、时间点、显示模式 |
| 底部状态 HUD | 能力点、阶段完成、作业提醒 |

### 5.3 选中态规则

1. 选中框只属于编辑器，不进入最终视频。
2. 选中框使用细蓝色描边和角点，不使用大面积遮罩。
3. 鼠标悬停可显示模块名称，但不应遮挡阅读。
4. 锁定布局下不显示拖拽手柄，避免暗示自由排版能力。

## 6. 右侧属性编辑面板

### 6.1 面板结构

右侧属性面板建议分为：

1. 面板标题：当前选中对象名称。
2. 基础字段区：标题、名称、正文、标签。
3. 状态区：显示模式、启用状态、当前状态。
4. 时间区：触发时间、结束时间、持续时间、使用当前时间。
5. 绑定区：关联阶段、地图节点、任务或能力点。
6. 高级区：优先级、显示模式、布局预设。

### 6.2 默认空状态

未选中任何模块时，右侧面板显示项目概览：

1. 课程标题。
2. 主视频状态。
3. 阶段数量。
4. 事件数量。
5. 渲染前待修正项。

### 6.3 字段即时反馈

用户修改字段后：

1. 中央预览画面应即时更新。
2. 时间相关字段应同步到底部时间轴。
3. 若字段导致冲突，面板内显示就地错误，不只在顶部提示。

## 7. 底部时间轴配置区

### 7.1 基础结构

底部时间轴配置区包含三个主要视图：

1. 阶段视图：配置 CourseStage。
2. 事件视图：配置 TimelineEvent。
3. 校验视图：显示时间重叠、缺失字段、提示过短等问题。

第一版可使用标签页切换，不要求复杂多轨剪辑时间线。

### 7.2 阶段视图

阶段视图字段：

1. 阶段名称。
2. 短名称。
3. 开始时间。
4. 结束时间。
5. 关联地图节点。
6. 默认任务。
7. 默认重点提示。
8. 显示状态。

操作：

1. 新增阶段。
2. 删除阶段。
3. 调整阶段顺序。
4. 使用当前时间写入开始或结束时间。
5. 点击阶段跳转预览到该阶段开始时间。

### 7.3 事件视图

事件视图字段：

1. 启用状态。
2. 触发时间。
3. 结束时间或持续时间。
4. 事件类型。
5. 目标模块。
6. 标题。
7. 正文。
8. 关联对象。
9. 优先级。

操作：

1. 新增事件。
2. 删除事件。
3. 禁用事件。
4. 使用当前时间写入触发时间。
5. 点击事件跳转预览到触发时间。
6. 按目标模块筛选事件。

### 7.4 当前时间与使用当前时间

编辑器必须稳定显示当前主视频时间。用户点击“使用当前时间”时：

1. 如果正在编辑阶段开始时间，则写入该字段。
2. 如果正在编辑阶段结束时间，则写入该字段。
3. 如果正在编辑事件触发时间，则写入 startTime。
4. 如果正在编辑提示结束时间，则写入 endTime。
5. 写入后预览状态立即重新计算。

## 8. 保存、预览、渲染入口

### 8.1 保存

保存项目配置，包括：

1. 素材引用。
2. 课程基础信息。
3. 布局显示模式。
4. 课程阶段。
5. 时间轴事件。
6. 主题预设。

### 8.2 预览

预览分为：

1. 当前时间点预览。
2. 从当前时间播放预览。
3. 全片 HUD 预览。

预览时可显示编辑器播放器控件，但控件必须在最终视频画框外。

### 8.3 渲染

点击渲染后先显示检查清单：

1. 主视频已导入。
2. 课程标题已填写。
3. 至少有一个阶段。
4. 阶段时间顺序正确。
5. 至少有一个关键时间轴事件。
6. 提示类事件有持续时间。
7. 最终视频不包含播放器控件。
8. HUD 遮挡风险已检查。

通过检查后进入 MP4 渲染流程。

## 9. 编辑器不做的事

第一版编辑器不提供：

1. 多轨剪辑。
2. 复杂转场。
3. 音频混音。
4. 字幕精剪。
5. 自由画布拖拽。
6. 任意图层排序。
7. 网页播放器皮肤配置。
8. 最终视频交互能力配置。
