# 团队角色指南

本项目适合小团队分工协作。每个角色都应遵守同一条边界：最终输出是无播放器控件的 16:9 MP4，主视频永远优先。

## 课程主理人

负责：

1. 确认课程标题、本节标题和课程编号。
2. 确认课程结构和阶段切点。
3. 确认任务、重点提示、总结和作业文案。
4. 审核最终样片是否符合课程意图。
5. 决定是否交付。

不负责：

1. 运行渲染命令。
2. 修 JSON 语法或 schema 错误。
3. 调整 Remotion 或脚本代码。
4. 处理 Git、大文件或依赖安装问题。

交付物：

1. 课程大纲。
2. 阶段确认表。
3. HUD 文案确认意见。
4. 样片放行结论。

## 后期制作人员

负责：

1. 放置主视频、讲师视频和头像。
2. 填写或修改 lesson 配置。
3. 配置阶段时间点和时间轴事件。
4. 运行预检、smoke、still、clip 和完整渲染。
5. 检查输出文件是否存在并可播放。

不负责：

1. 最终课程语义判断。
2. 客户素材授权确认。
3. schema 设计和渲染器代码维护。
4. 承诺云端、自动字幕或 AI 自动识别能力。

交付物：

1. 素材清单。
2. lesson JSON 修改记录。
3. 输出 MP4。
4. smoke/still/clip 证据路径。

## 内容助理

负责：

1. 修改任务名称。
2. 修改提示文案。
3. 修改章节和地图节点名称。
4. 检查中文文案长度。
5. 将课程主理人的口头说明整理为短句。

不负责：

1. 最终教学取舍。
2. 素材授权判断。
3. 命令排错。
4. 改动 schema、渲染逻辑或模板尺寸。

交付物：

1. 课程基础信息表。
2. 任务文案表。
3. 地图节点表。
4. 提示、总结和作业文案表。
5. 文案过长问题清单。

## 质检人员

负责：

1. 检查主视频是否清楚。
2. 检查 HUD 是否遮挡主视频。
3. 检查时间轴是否按时变化。
4. 检查地图、任务、提示、总结和作业是否正确出现。
5. 检查音频是否正常，是否有回声。
6. 检查最终视频无播放器控件。
7. 检查 CourseStageBar 没有被做成播放器进度条。

不负责：

1. 临场重写课程结构。
2. 替换素材或重新配置时间轴。
3. 修复代码。
4. 私自放行有 P0 问题的成片。

交付物：

1. `QA_CHECKLIST.md` 检查记录。
2. `RELEASE_CHECKLIST.md` 放行记录。
3. 阻断问题列表。
4. 放行、带问题放行或不放行结论。

## 技术维护人员

负责：

1. 维护 `package.json` 命令。
2. 维护 `scripts/` 下校验、预检、渲染和批量脚本。
3. 维护 `src/schemas/` 下 schema。
4. 维护 `src/remotion/` 最终视频渲染边界。
5. 维护 `src/data/course.manifest.json` 和批量报告口径。
6. 修复脚本、字段和输出路径问题。

不负责：

1. 决定课程内容是否准确。
2. 判断客户素材是否授权。
3. 用代码绕过主视频缺失预检。
4. 把播放器控件、编辑器控件或交互暗示加入最终 MP4。

交付物：

1. 命令执行记录。
2. 修复说明。
3. 批量报告。
4. schema 或脚本变更说明。
5. 后续维护建议。

## 协作交接规则

1. 课程主理人先给课程结构，后期制作人员再配置时间轴。
2. 后期制作人员完成 smoke/still/clip 后交给质检人员。
3. 质检人员发现内容问题交回课程主理人，发现素材或配置问题交回后期制作人员，发现脚本问题交给技术维护人员。
4. 所有角色都不能把最终视频做成播放器。
5. 所有角色都不能提交真实视频、客户素材、密钥或 `out/` 渲染产物。
