# 《视频课程套壳》原始需求

## 第 0 阶段补充要求

### 时间轴联动、课程阶段条与可视化布局编辑

### 一、补充核心定位：它不是静态套壳，而是时间轴驱动的课程界面

“视频课程套壳”不是简单给视频加一张静态遮罩，也不是普通视频模板工具。

它的核心应该定义为：

一个能跟随课程视频时间进度变化的课程界面渲染工具。

用户上传课程视频后，可以手动配置不同时间点发生的界面变化。最终系统根据这些时间点，把课程 HUD、章节提示、重点提醒、任务状态、地图节点、底部阶段条等内容同步到视频中。

第一版不需要 AI 自动识别内容，也不需要自动生成章节。第一版采用手动填写时间点的方式，让用户自己把课程内容和界面变化对应起来。

### 二、时间轴动态事件类型

时间轴联动不应该只理解为“地图节点点亮”。地图点亮只是其中一种表现形式。

第一版应该至少考虑以下几类动态事件。

#### 1. 课程地图节点点亮

用于告诉学员课程路径推进到了哪里。

示例：

- 05:00：点亮地图节点「信源导入」
- 10:00：点亮地图节点「导演椅」
- 15:00：点亮地图节点「技能释放」

作用：

让学员知道当前处于课程整体路径中的哪个位置。

#### 2. 重点内容提醒弹出

用于强调当前片段最重要的知识点。

示例：

- 03:20：弹出「新手重点：不要直接点击生成，先点 Customize」
- 08:10：弹出「关键概念：听众越明确，AI 播客越精准」
- 12:30：弹出「提示词结构：听众、目标、焦点、角色、风格、结构」

作用：

帮助学员快速抓住当前片段的重点，而不是只被动听课。

#### 3. 任务追踪状态变化

用于显示当前操作任务或学习任务。

示例：

- 00:00：当前任务为「理解本节课目标」
- 04:00：当前任务切换为「上传资料」
- 07:00：当前任务切换为「打开 Studio」
- 10:00：当前任务切换为「点击 Customize」
- 15:00：当前任务切换为「生成 AI 播客」

作用：

让课程从普通讲解变成“任务推进式学习”。

#### 4. 底部课程模块切换

用于显示当前正在讲哪个知识模块。

示例：

- 00:00：当前模块「开场与课程目标」
- 05:00：当前模块「信源导入」
- 10:00：当前模块「Customize 设置」
- 15:00：当前模块「提示词结构」
- 20:00：当前模块「作业挑战」

作用：

让底部 HUD 成为学员的“学习导航条”。

#### 5. 技能 / 能力点解锁

用于把知识点包装成能力模块。

示例：

- 06:00：解锁「听众定位」
- 09:00：解锁「目标设定」
- 12:00：解锁「焦点聚合」
- 16:00：解锁「角色设定」
- 18:00：解锁「风格控制」
- 21:00：解锁「结构输出」

作用：

增强课程的游戏化学习体验，让学员有“能力逐步解锁”的感觉。

#### 6. 警告 / 避坑提示

用于提醒学员避免常见错误。

示例：

- 05:30：显示「新手陷阱：不要直接点击生成」
- 11:20：显示「注意：提示词不能只写‘帮我总结’」
- 17:40：显示「避坑：不要一次上传无关资料」

作用：

强化课程的实战价值。

#### 7. 阶段总结提示

用于在每个阶段结束时给学员一个小结。

示例：

- 09:50：显示「阶段完成：你已经完成信源导入」
- 14:50：显示「阶段完成：你已经掌握 Customize 的核心逻辑」
- 19:50：显示「阶段完成：你已经理解提示词六要素」

作用：

帮助学员建立课程结构感。

#### 8. 作业 / 行动提醒

用于课程末尾或阶段末尾提示学员下一步操作。

示例：

- 22:00：显示「课后任务：上传一份自己的资料」
- 23:00：显示「行动清单：用私人教练模板生成一次 AI 播客」

作用：

让课程从“看完”转化为“实际操作”。

### 三、底部课程阶段进度条

第一版应设计一个底部“课程阶段进度条”。

注意：这个进度条不是播放器控件，不承担播放、暂停、拖动、倍速等功能。它是视频画面内部的课程结构提示，用来告诉学员：

- 当前视频讲到哪个阶段
- 每个阶段大概占课程的哪一段
- 已经讲完哪些阶段
- 正在讲哪个阶段
- 后面还有哪些阶段

它应该和视频时间基本同步。

### 四、课程阶段进度条的表现方式

底部课程阶段条可以把一节课拆成几个阶段，例如：

开场目标 | 信源导入 | Customize 设置 | 提示词结构 | 作业挑战

当视频播放到不同时间时，阶段条状态发生变化：

- 已经过的阶段：点亮或标记完成
- 当前阶段：高亮、发光、显示当前标识
- 未来阶段：灰色或半透明

示例：

`[已完成]开场目标  ━  [当前]信源导入  ━  [未开始] Customize 设置  ━  [未开始]提示词结构  ━  [未开始]作业挑战`

或者更紧凑：

`● 开场目标   ◉ 信源导入   ○ Customize   ○ 提示词结构   ○ 作业挑战`

### 五、课程阶段进度条与课程地图的关系

底部阶段进度条和右侧课程地图可以联动，但它们不是完全重复。

#### 底部阶段进度条

主要表达：

- 当前课程阶段
- 视频内容推进顺序
- 每一段讲什么
- 学员现在处于哪一段

它更像课程视频内置的“章节导航条”。

#### 右侧课程地图

主要表达：

- 本节课的学习路径
- 阶段之间的关系
- 完成感和任务感
- 游戏化学习路径

它更像 RTS / RPG 里的小地图或任务路径。

#### 联动方式

当底部阶段条进入某个阶段时，右侧课程地图对应节点也应该点亮。

例如：

- 底部阶段条进入「信源导入」
- 右侧课程地图节点「信源导入」同步高亮
- 任务追踪中对应任务也可以变成当前任务
- 新手重点可以切换为与这一阶段相关的提示

### 六、关于“可点击跳转”的边界

很多在线教学视频会在播放器里内置章节进度条，用户可以点击某个章节跳转。

本产品第一版需要区分两种场景。

#### 1. 在编辑器预览中，可以点击跳转

在“视频课程套壳”的编辑器里，用户需要配置时间点，所以预览界面可以支持：

- 点击底部阶段条跳到对应时间
- 点击课程地图节点跳到对应时间
- 点击任务节点跳到对应时间
- 点击“使用当前时间”记录时间点

这有助于用户快速配置课程结构。

#### 2. 在最终导出视频中，不可点击

最终输出的是 MP4 视频。MP4 内部的 HUD 只是画面内容，不能真正点击跳转。

所以最终成片里的底部阶段条只负责视觉提示，不负责交互跳转。

#### 3. 未来版本可以支持网页播放器模式

未来如果产品增加“自定义网页播放器”，则可以让底部阶段条真正可点击跳转。但第一版不做这个能力。

第一版只做：

- 编辑器里可点击预览跳转
- 最终视频里只显示同步视觉效果

### 七、时间轴配置能力

第一版应该提供一个简单、直观的时间轴配置功能。

用户可以在编辑器里配置：

- 阶段名称
- 阶段开始时间
- 阶段结束时间，或由下一个阶段开始时间自动推算
- 对应地图节点
- 对应任务名称
- 对应重点提示
- 对应底部状态文案

示例：

第一版可以先采用表格式配置，不需要复杂拖拽时间轴。但必须能让用户手动设置时间点。

### 八、可视化界面布局编辑

界面布局是本产品的重中之重。

产品经理阶段必须明确：用户不应该只在表单里改文字，还应该尽可能在预览画面上直接看到这些内容放在哪里、效果如何。

第一版建议采用“可视化预览 + 右侧属性面板”的编辑方式。

#### 推荐编辑器结构

```text
┌──────────────────────────────────────────────┐
│ 顶部工具栏：保存 / 预览 / 渲染 / 导出配置       │
├──────────────────────────────┬───────────────┤
│                              │ 属性编辑面板   │
│                              │               │
│      课程画面实时预览          │ 修改标题       │
│      点击某个模块即可选中       │ 修改任务       │
│                              │ 修改地图节点   │
│                              │ 修改重点提示   │
├──────────────────────────────┴───────────────┤
│ 时间轴配置区：阶段条 / 时间节点 / 当前时间       │
└──────────────────────────────────────────────┘
```

### 九、可视化编辑器中的操作方式

用户应该可以：

- 在预览画面中点击顶部标题栏，右侧属性面板显示标题相关字段。
- 点击讲师头像区域，右侧属性面板显示讲师名称、身份、头像或视频设置。
- 点击右侧任务追踪，右侧属性面板显示任务名称配置。
- 点击课程地图，右侧属性面板显示地图节点名称和状态配置。
- 点击底部阶段条，右侧属性面板显示阶段名称、时间点和对应提示。
- 拖动或播放视频到某个位置，点击“使用当前时间”，把当前时间写入阶段开始时间。
- 点击某个阶段，预览画面跳转到该阶段对应的视频时间。
- 修改文字后，预览画面立即更新。

### 十、第一版布局编辑边界

第一版需要可视化，但不建议做成完全自由拖拽的复杂设计软件。

第一版可以采用：

- 固定布局
- 可视化点选
- 属性面板编辑内容
- 少量布局开关
- 少量位置预设

第一版暂不建议支持：

- 任意拖拽所有模块
- 任意缩放所有模块
- 多层级自由排版
- 类似 Figma 的复杂编辑器
- 用户自定义所有样式

原因是：第一版的重点是快速稳定地生成课程视频，而不是做一个复杂设计软件。

### 十一、第一版可支持的布局配置

第一版可以支持简单的布局设置，例如：

#### 1. 讲师小窗位置

可选：

- 左下角
- 右下角
- 左侧底部 HUD 内
- 隐藏讲师小窗

默认建议：左下角，放入底部 HUD 内。

#### 2. 右侧辅助栏显示

可选：

- 显示
- 隐藏
- 只显示重点提示
- 只显示任务追踪
- 只显示课程地图

默认建议：显示完整右侧辅助栏。

#### 3. 底部阶段条显示

可选：

- 显示
- 隐藏
- 紧凑模式
- 标准模式

默认建议：显示紧凑模式。

#### 4. 顶部课程信息栏显示

可选：

- 显示
- 隐藏

默认建议：显示。

#### 5. 主视频适配方式

可选：

- 完整显示
- 填充显示
- 适配宽度
- 适配高度

默认建议：完整显示，优先保证课程内容不被裁切。

### 十二、产品经理 Agent 需要补充输出的内容

产品经理 Agent 在第 0 阶段必须额外输出以下内容：

#### 1. 时间轴事件模型

说明第一版支持哪些动态事件：

- 地图节点点亮
- 重点提示切换
- 任务状态变化
- 底部阶段条变化
- 能力点解锁
- 阶段总结
- 作业提醒

#### 2. 底部课程阶段条设计

说明：

- 阶段条放在哪里
- 它和播放器进度条的区别
- 它如何和视频时间同步
- 它如何和右侧地图联动
- 它在编辑器中是否可点击
- 它在最终视频中为什么不可点击

#### 3. 可视化布局编辑设计

说明：

- 预览画面如何展示
- 用户如何点击模块
- 右侧属性面板如何编辑
- 时间轴配置区如何工作
- 哪些布局可以调
- 哪些布局第一版不开放

#### 4. 编辑器页面信息架构

至少包含：

- 顶部工具栏
- 中央实时预览区
- 右侧属性面板
- 底部时间轴配置区
- 素材选择区
- 渲染导出入口

#### 5. 最终视频画面信息架构

至少包含：

- 主视频区域
- 顶部课程信息栏
- 右侧辅助栏
- 讲师小窗
- 底部课程阶段条
- 底部状态 HUD
- 课程地图
- 重点提示
- 任务追踪

### 十三、更新后的产品核心原则

产品经理 Agent 必须遵守以下原则：

- 本产品不是静态套壳工具，而是时间轴驱动的课程界面工具。
- 时间轴联动是第一版核心能力。
- 底部课程阶段条是关键学习导航组件。
- 界面布局设计是产品重中之重。
- 编辑器需要尽可能可视化，而不只是普通表单。
- 第一版可以固定布局，但必须支持可视化点选和属性编辑。
- 主视频内容永远是第一优先级。
- 最终视频中不能出现真正的播放器控件。
- 编辑器中可以有播放器控件，因为它用于配置时间点。
- 最终输出 MP4 中的阶段条只负责视觉提示，不负责点击交互。
