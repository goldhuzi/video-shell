# 第 1 阶段设计简报

## 1. 阶段目标

第 1 阶段的目标是把《视频课程套壳》的产品定义转化为可执行的界面布局与视觉系统规格。

本阶段不实现 React、不实现 Remotion、不实现业务功能，只输出后续 Agent 可直接使用的设计依据：

1. 最终导出视频的 16:9 HUD 布局。
2. 本地可视化编辑器的页面结构。
3. 第一版 HUD 组件的职责、状态和数据来源。
4. “AI 战术课程 HUD”视觉系统。
5. 时间轴联动 UI 的配置方式与最终视频表现。
6. 本阶段新增设计决策与待确认问题。

## 2. 设计对象

本阶段需要同时定义两类界面，但必须明确区分：

| 界面 | 用途 | 是否可交互 | 是否进入最终 MP4 |
| --- | --- | --- | --- |
| 最终视频界面 | 渲染给学员观看的课程 HUD 成片 | 否 | 是 |
| 编辑器界面 | 给创作者配置素材、模块、阶段和事件 | 是 | 否 |

最终视频界面是产品的输出结果。编辑器界面是生产这个结果的工具。两者共享同一套 HUD 模块语义，但不共享交互控件。

## 3. 核心设计原则

### 3.1 主视频优先

主课程视频永远是视觉权重最高的内容。HUD 只能提供结构、任务、提醒和状态，不应抢占学员注意力。

执行要求：

1. 主视频区域面积必须最大。
2. HUD 不得遮挡主视频中的关键按钮、代码区、菜单、演示主体或字幕。
3. 右侧栏、底部栏和讲师小窗都必须使用安全区域设计。
4. 重点提示应短句化，避免大段文字压迫主视频。

### 3.2 最终视频不是播放器

最终 MP4 中禁止出现任何播放器控件，包括播放、暂停、倍速、音量、全屏、可拖动进度条、拖拽手柄和时间滑块。

底部课程阶段条是学习导航，不是播放进度条。它显示课程结构状态，不表达“可拖动播放位置”。

### 3.3 编辑器允许播放器控件

编辑器中可以出现播放、暂停、拖动、当前时间、使用当前时间等控件，因为创作者需要用它们配置阶段和事件时间点。

执行要求：

1. 编辑器播放器控件必须位于最终视频预览画框之外或明确标注为编辑器控制层。
2. 渲染 Agent 只接收最终视频画面层，不接收编辑器控件层。
3. UI Agent 需要在视觉上区分“视频成片预览”和“编辑器操作控件”。

### 3.4 固定布局，有限配置

第一版采用固定布局，不做 Figma 式自由画布。用户可以点选模块并修改内容，也可以使用有限布局预设，但不能任意拖拽、缩放、改变层级。

第一版允许配置：

1. 讲师小窗显示、隐藏和位置预设。
2. 右侧辅助栏显示模式。
3. 底部课程阶段条标准或紧凑模式。
4. 顶部课程信息栏显示状态。
5. 主视频适配方式。
6. 基础主题色预设或品牌色输入。

第一版不允许配置：

1. 任意拖拽模块。
2. 任意缩放模块。
3. 任意图层排序。
4. 任意改造字体、边框、动效和装饰。
5. 将最终视频变成网页播放器。

### 3.5 时间轴驱动，而非静态遮罩

HUD 模块必须能随主视频时间变化。第一版至少要支持：

1. 底部阶段条状态变化。
2. 课程地图节点点亮。
3. 任务状态切换。
4. 重点提示弹出或切换。
5. 能力点解锁。
6. 阶段总结。
7. 作业或行动提醒。

所有变化都以主课程视频时间为唯一基准。

## 4. 最终视频界面与编辑器界面的关系

### 4.1 共享对象

编辑器中央预览区应显示最终视频画面的真实布局。用户点击预览画面中的 HUD 模块时，右侧属性面板编辑的是该最终视频模块的数据。

共享对象包括：

1. TopHeader。
2. MainVideoFrame。
3. LecturerMiniCard。
4. WarningPanel。
5. TaskTracker。
6. ChapterMap。
7. CourseStageBar。
8. BottomStatusHud。

### 4.2 分离对象

以下内容只属于编辑器，不进入最终视频：

1. 顶部工具栏。
2. 素材选择区。
3. 保存、预览、渲染按钮。
4. 播放器播放、暂停、拖动、音量等预览控件。
5. 右侧属性面板。
6. 底部时间轴配置表。
7. 选中框、参考线、模块名称浮层。
8. 校验提示、错误提示、渲染前检查清单。

### 4.3 状态同步关系

编辑器中的当前播放时间会驱动中央预览区展示对应 HUD 状态：

1. 当前时间进入某阶段时，CourseStageBar 高亮当前阶段。
2. 当前阶段绑定地图节点时，ChapterMap 高亮对应节点。
3. 当前阶段绑定默认任务时，TaskTracker 切换当前任务。
4. 当前时间命中提示事件时，WarningPanel 显示该提示。
5. 当前时间命中能力点事件时，BottomStatusHud 显示解锁反馈。

## 5. 设计交付标准

第 1 阶段完成后，应满足以下标准：

1. 后续 UI Agent 能根据文档画出稳定布局。
2. 后续前端 Agent 能根据文档实现点选编辑、属性面板和时间轴配置区。
3. 后续 Remotion Agent 能根据组件规格和时间轴规则渲染最终 MP4。
4. 所有文档都明确区分最终视频和编辑器。
5. 所有文档都避免把产品设计成普通剪辑软件、播放器或课程平台。
