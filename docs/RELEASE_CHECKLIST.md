# 交付检查清单

本清单用于最终交付前。任何 P0 问题未解决时，不应交付。

## 渲染前

- [ ] lesson 配置通过 `npm run validate:lessons`。
- [ ] 单节通过 `npm run preflight:render -- <lessonId>`。
- [ ] 主视频存在。
- [ ] 讲师素材存在或 fallback 策略明确。
- [ ] 课程标题、本节标题、课程序号已确认。
- [ ] 时间轴阶段切点已确认。
- [ ] 提示、总结和作业文案已确认。
- [ ] 音频模式已确认，默认建议 `main-only`。
- [ ] 输出目录已确认。
- [ ] 输出文件名以 `.mp4` 结尾。
- [ ] 真实素材授权已确认。

## 渲染后

- [ ] MP4 可播放。
- [ ] 分辨率为 1920 x 1080。
- [ ] 视频编码和封装正常。
- [ ] 音频正常。
- [ ] 主视频清晰。
- [ ] HUD 正常显示。
- [ ] 时间轴联动正常。
- [ ] 无播放器控件。
- [ ] CourseStageBar 不是播放器进度条。
- [ ] 无明显遮挡。
- [ ] 文件命名正确。
- [ ] 输出路径已记录。

## 批量交付

- [ ] 所有课程均输出。
- [ ] batch validate report 无失败。
- [ ] batch preflight report 无阻断错误。
- [ ] batch render report 无未处理 failed。
- [ ] failed lessons 已处理或已记录不交付。
- [ ] `out/final/` 如需使用，已人工整理。
- [ ] 交付目录只放 QA 放行的 MP4。
- [ ] 不提交 `out/` 到 Git。

## Git 检查

- [ ] 未提交真实主视频。
- [ ] 未提交讲师视频。
- [ ] 未提交真实头像或客户素材。
- [ ] 未提交 `out/` 渲染产物。
- [ ] 未提交 `.env` 或密钥。
- [ ] lesson JSON 中没有本机绝对路径。
- [ ] `git status --short` 已检查。

## 放行结论

- [ ] 课程主理人确认内容可交付。
- [ ] 质检人员确认画面和音频可交付。
- [ ] 技术维护人员确认命令和报告无阻断错误。
- [ ] 最终结论：放行。
- [ ] 如果带问题放行，问题和责任人已写清楚。
