# UI 决策记录

## 1. 本阶段已确定决策

### UID001：采用“AI 战术课程 HUD”作为第一版视觉方向

决策：

第一版视觉方向确定为轻量科幻、RTS 指挥界面感、深色科技、蓝紫能量光、金属细边框、克制高级。

理由：

该方向能强化任务推进和课程结构感，同时与普通剪辑软件、播放器和课程平台拉开差异。

影响：

1. 视觉系统采用深色底板。
2. 当前状态使用蓝色能量光。
3. 完成状态使用青色。
4. 能力解锁使用紫色。
5. 警告和作业提醒使用琥珀色或红色。

### UID002：最终视频采用 1920 x 1080 为设计基准

决策：

最终视频布局以 16:9、1920 x 1080 为设计基准，后续渲染可按比例缩放。

理由：

16:9 是课程录屏和横屏教程视频的主流比例，1920 x 1080 能提供清晰的布局尺寸依据。

影响：

1. 文档中给出推荐坐标和尺寸。
2. UI Agent 可按 1080p 出图。
3. Remotion Agent 可按比例实现响应式缩放。

### UID003：右侧辅助栏默认同时显示地图、任务和重点提示

决策：

右侧辅助栏默认完整显示 ChapterMap、TaskTracker、WarningPanel。

理由：

右侧栏能承载主要辅助信息，并避免在主视频上大面积叠加文字。

影响：

1. 主视频区域默认偏左。
2. 右侧栏宽度建议 360 至 420 px。
3. 右侧栏可提供显示模式，但默认完整显示。

### UID004：底部课程阶段条使用段块和节点表达，不使用播放器式进度填充

决策：

CourseStageBar 使用阶段段块、节点、连接线和状态标记表达学习导航，不使用可拖动播放头或连续进度填充。

理由：

必须避免学员把阶段条误认为播放器进度条。

影响：

1. 最终视频不显示播放时间和总时长。
2. 当前阶段以高亮段块表达。
3. 编辑器中阶段条可点击跳转，但最终视频不可点击。

### UID005：重点提示优先固定在右侧 WarningPanel

决策：

第一版重点提示默认显示在右侧 WarningPanel，不默认在主视频上弹大面积浮层。

理由：

主视频内容优先，右侧栏能降低遮挡风险。

影响：

1. hint_show、stage_summary、homework_reminder 默认目标模块为 WarningPanel。
2. 底部状态 HUD 只同步短文案。
3. 主视频内弹层作为后续可选模式，不进入第一版默认路径。

### UID006：编辑器预览画框内只显示最终视频内容

决策：

中央预览的 16:9 画框内尽量只显示最终视频会被渲染的内容；播放器控件放在画框外。

理由：

这样能减少“编辑器控件是否会进成片”的理解成本。

影响：

1. 播放、暂停、拖动、当前时间显示位于画框外。
2. 选中框和模块名称浮层只在编辑器状态显示，不进入渲染层。
3. 渲染 Agent 只接收画框内最终视频层。

### UID007：第一版时间轴 UI 使用阶段表 + 事件表，不做复杂多轨剪辑线

决策：

底部时间轴配置区采用阶段视图、事件视图和校验视图，不做专业剪辑软件式多轨时间线。

理由：

本产品不是普通剪辑软件。阶段和事件才是核心对象。

影响：

1. 配置体验围绕 CourseStage 和 TimelineEvent。
2. 支持“使用当前时间”写入字段。
3. 支持点击阶段或事件跳转预览。

### UID008：讲师小窗作为 P1 模块，默认底部左侧或嵌入底部 HUD

决策：

讲师小窗默认不抢占右侧核心信息区，优先放在底部左侧或底部 HUD 内。

理由：

讲师存在感重要，但不能牺牲主视频可读性和时间轴 HUD 的核心模块。

影响：

1. 讲师小窗可隐藏。
2. 支持有限位置预设。
3. 没有讲师视频时可用头像替代。

### UID009：最终视频 HUD 动效采用短、少、可解释的状态动效

决策：

动效只用于表达状态变化，例如节点点亮、任务切换、提示出现和能力解锁。

理由：

过度动画会抢主视频注意力，并增加渲染复杂度。

影响：

1. 动效时长主要控制在 120 至 400 ms。
2. 不使用无限循环装饰动画。
3. 支持 reduced motion 的降级策略。

### UID010：第一版只定义一套默认主题

决策：

第一版只定义“AI 战术课程 HUD”默认主题，允许轻量品牌色点缀，不做复杂主题市场。

理由：

第一版核心是验证时间轴驱动课程 HUD，不是验证皮肤系统。

影响：

1. DESIGN_SYSTEM.md 作为默认视觉源。
2. 主题预设不成为 P0。
3. UI 和 Remotion 实现可先围绕一套 token。

## 3. 仍需确认的问题

### UIQ001：右侧辅助栏在主视频信息密集时是否允许自动折叠

当前建议：

第一版保留手动显示模式，不做自动识别和自动折叠。

待确认：

1. 是否需要提供“只显示任务”或“只显示重点”的快速模式。
2. 是否允许某些课程片段临时隐藏右侧栏。

### UIQ002：主视频安全区是否需要可视化参考线

当前建议：

编辑器提供安全区参考线开关，默认关闭，渲染前检查提醒用户人工确认。

待确认：

1. 是否进入 MVP P0。
2. 参考线是否支持左、右、下三个风险区域。

### UIQ003：阶段条标准模式最多显示几个阶段

当前建议：

标准模式支持 3 至 8 个阶段。超过 8 个阶段建议使用紧凑模式。

待确认：

1. 是否设置硬上限。
2. 超过上限时是自动切换紧凑模式，还是提示用户手动切换。

### UIQ004：是否需要品牌 Logo 区

当前建议：

第一版支持文字型课程代号或品牌标识，不强制支持上传 Logo。

待确认：

1. 是否需要图片 Logo。
2. Logo 放在 TopHeader 还是 BottomStatusHud。
3. 是否需要工具水印。

### UIQ005：提示类事件是否允许主视频内弹层

当前建议：

第一版默认只使用右侧 WarningPanel 和底部状态 HUD。主视频内弹层后置。

待确认：

1. 是否有必须覆盖主视频的提示场景。
2. 如果允许，安全区域和遮挡校验如何处理。

### UIQ006：讲师小窗视频是否必须与主视频同步

当前建议：

讲师视频作为独立素材时默认从 0 秒同步播放，时长不一致时后续由工程方案处理。

待确认：

1. 是否允许手动设置讲师视频起始偏移。
2. 讲师视频短于主视频时是冻结最后一帧、循环还是隐藏。

### UIQ007：编辑器是否需要移动端适配

当前建议：

第一版编辑器优先桌面端，不做移动端完整编辑体验。

待确认：

1. 是否需要平板横屏可用。
2. 是否需要移动端仅预览项目。

### UIQ008：主题是否允许用户输入品牌色

当前建议：

可作为 P1 提供单一品牌色输入，并自动映射到能量高亮，不开放完整 token 编辑。

待确认：

1. 是否需要品牌色输入。
2. 是否需要校验对比度。

## 4. 给后续 Agent 的注意事项

### 4.1 给 UI Agent

请基于固定布局出图，不要设计自由拖拽画布。重点检查主视频面积、右侧栏可读性、阶段条非播放器感和蓝紫发光克制度。

### 4.2 给前端 Agent

请优先实现点选模块、右侧属性面板、阶段表、事件表和“使用当前时间”。不要把实现方向带向普通剪辑软件多轨时间线。

### 4.3 给 Remotion 渲染 Agent

请只渲染最终视频画面层，不渲染编辑器控件、选中框、属性面板、预览播放器控件。所有 HUD 状态以主视频时间计算。
