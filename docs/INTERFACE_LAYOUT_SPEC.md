# 界面布局规格

## 1. 布局设计原则

### 1.1 主视频内容优先

主课程视频是最终成片的核心。所有界面模块都必须围绕主视频服务：

1. 不遮挡主视频中的关键操作区域。
2. 不抢夺学员对课程内容的注意力。
3. 不用大面积装饰压缩主视频可视区域。
4. 默认优先完整显示主视频。

### 1.2 HUD 是学习导航，不是播放器

最终视频中的顶部栏、右侧栏、地图、任务、重点提示和底部阶段条都是视频画面内容，不具备交互功能。

特别说明：

1. 底部课程阶段条不是播放器进度条。
2. 最终视频中不能出现播放、暂停、拖动、倍速、音量、全屏等播放器控件。
3. 编辑器中可以出现播放器控件，因为它们用于配置时间点。

### 1.3 固定布局优先

第一版采用固定布局和有限配置，不做自由排版。这样可以保证：

1. 渲染稳定。
2. 配置简单。
3. 成片一致。
4. 后续 UI、前端、Remotion 实现边界清晰。

## 2. 最终视频画面布局

### 2.1 输出规格

1. 输出比例：16:9。
2. 输出形式：MP4。
3. 画面结构：主视频 + 课程 HUD 叠加层。
4. 交互能力：无。

### 2.2 推荐画面结构

```text
┌────────────────────────────────────────────────────────────┐
│ 顶部课程信息栏                                              │
├──────────────────────────────────────────┬─────────────────┤
│                                          │ 右侧辅助栏        │
│                                          │ ┌───────────────┐ │
│                                          │ │ 课程地图       │ │
│              主课程视频区域               │ ├───────────────┤ │
│                                          │ │ 任务追踪       │ │
│                                          │ ├───────────────┤ │
│                                          │ │ 重点提示       │ │
│                                          │ └───────────────┘ │
├──────────────────────────────────────────┴─────────────────┤
│ 讲师小窗 / 底部状态 HUD / 底部课程阶段条                     │
└────────────────────────────────────────────────────────────┘
```

具体视觉比例由 UI Agent 细化，但产品层必须保证：主视频区域面积最大，右侧辅助栏和底部 HUD 是辅助信息层。

## 3. 最终视频模块规格

### 3.1 主课程视频区域

位置：

1. 画面中央偏左或主体区域。
2. 占据最大可视面积。

用途：

1. 展示课程录屏、演示、讲解主体。
2. 承载学员主要注意力。

优先级：P0。

是否随时间变化：

1. 主视频自身随时间播放。
2. 布局位置默认不随时间变化。

约束：

1. 默认完整显示。
2. 禁止被 HUD 大面积遮挡。
3. 如用户选择填充显示，需要提示可能裁切内容。

### 3.2 顶部课程信息栏

位置：

1. 画面顶部。
2. 横向展示，覆盖宽度由 UI 方案确定。

用途：

1. 显示课程标题。
2. 显示章节名称。
3. 显示课程编号或当前课次。
4. 建立课程上下文。

优先级：P0。

是否随时间变化：

1. 默认不随时间变化。
2. 可在后续支持随阶段显示不同副标题。

第一版字段：

1. 课程标题。
2. 章节标题。
3. 课程序号。
4. 可选状态标签。

### 3.3 右侧辅助栏

位置：

1. 画面右侧。
2. 与主视频并列或叠加在右侧安全区域。

用途：

1. 承载课程地图。
2. 承载任务追踪。
3. 承载重点提示。
4. 强化学习路径和当前行动。

优先级：P0。

是否随时间变化：

1. 内部模块随时间轴事件变化。
2. 右侧栏整体显示状态可配置，但默认显示。

显示模式：

1. 完整显示。
2. 隐藏。
3. 只显示重点提示。
4. 只显示任务追踪。
5. 只显示课程地图。

默认：完整显示。

### 3.4 课程地图

位置：

1. 右侧辅助栏上部。

用途：

1. 表达本节课学习路径。
2. 显示阶段之间的推进关系。
3. 提供游戏化完成感。

优先级：P0。

是否随时间变化：是。

变化方式：

1. 当前节点高亮。
2. 已完成节点点亮或标记完成。
3. 未开始节点保持低亮度。
4. 可与底部阶段条同步。

第一版状态：

1. 未开始。
2. 当前。
3. 已完成。
4. 可选锁定或解锁。

### 3.5 任务追踪

位置：

1. 右侧辅助栏中部。

用途：

1. 显示当前学习任务。
2. 让课程从“观看讲解”转为“推进任务”。

优先级：P0。

是否随时间变化：是。

变化方式：

1. 当前任务切换。
2. 任务状态从未开始变为进行中或已完成。
3. 可以显示下一步任务，但当前任务必须最突出。

第一版状态：

1. 未开始。
2. 当前。
3. 已完成。

### 3.6 重点提示

位置：

1. 右侧辅助栏下部。
2. 或在主视频安全区域内短时弹出，具体由 UI Agent 设计。

用途：

1. 强调当前片段最重要的知识点。
2. 提醒避坑。
3. 给出阶段总结或行动提醒。

优先级：P0。

是否随时间变化：是。

提示类型：

1. 重点内容。
2. 新手重点。
3. 警告或避坑。
4. 阶段总结。
5. 作业或行动提醒。

约束：

1. 文案应短。
2. 显示时间应足够阅读。
3. 不得遮挡主视频关键区域。

### 3.7 讲师小窗或头像

位置：

1. 默认左下角或底部 HUD 内。
2. 可选右下角。
3. 可隐藏。

用途：

1. 保留讲师存在感。
2. 展示讲师名称和身份。

优先级：P1。

是否随时间变化：

1. 小窗视频随时间播放。
2. 位置和基础信息默认不随时间变化。

第一版配置：

1. 讲师视频。
2. 讲师头像。
3. 讲师名称。
4. 讲师身份。
5. 位置预设。
6. 隐藏开关。

### 3.8 底部课程阶段条

位置：

1. 画面底部。
2. 位于底部 HUD 区域。

用途：

1. 表达当前课程阶段。
2. 告诉学员已经完成哪些阶段。
3. 告诉学员后续还有哪些阶段。
4. 作为学习导航，而不是播放器进度条。

优先级：P0。

是否随时间变化：是。

状态：

1. 已完成。
2. 当前。
3. 未开始。

显示模式：

1. 标准模式：显示完整阶段名称和状态。
2. 紧凑模式：使用点位、短名称或图标化状态。
3. 隐藏，非默认。

编辑器行为：

1. 可点击某个阶段跳转到对应时间。
2. 可选中阶段后在右侧属性面板编辑。

最终视频行为：

1. 不可点击。
2. 不可拖动。
3. 不显示播放控制。
4. 只作为同步视觉提示。

### 3.9 底部状态 HUD

位置：

1. 画面底部，与阶段条和讲师小窗协同。

用途：

1. 显示当前课程状态。
2. 显示能力点解锁或完成状态。
3. 承接短状态文案。

优先级：P1。

是否随时间变化：是。

变化方式：

1. 能力点解锁时显示短提示。
2. 阶段完成时显示完成提示。
3. 作业提醒时显示行动提示。

## 4. 编辑器页面布局

### 4.1 编辑器主结构

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部工具栏：项目名 / 保存 / 预览 / 渲染 / 导出配置             │
├──────────────┬──────────────────────────────┬────────────────┤
│ 素材选择区    │ 中央课程画面实时预览           │ 右侧属性面板     │
│ 主视频        │ 可点击模块                    │ 当前选中模块配置 │
│ 讲师视频/头像 │ 编辑器播放器控件               │ 时间与文案字段   │
├──────────────┴──────────────────────────────┴────────────────┤
│ 底部时间轴配置区：阶段条 / 事件列表 / 当前时间 / 使用当前时间   │
└──────────────────────────────────────────────────────────────┘
```

### 4.2 顶部工具栏

用途：

1. 显示项目名称。
2. 保存项目。
3. 进入预览。
4. 开始渲染。
5. 导出或导入配置。

优先级：P0。

注意：

1. 顶部工具栏是编辑器 UI，不属于最终视频画面。
2. 工具栏不能被渲染到 MP4 中。

### 4.3 素材选择区

用途：

1. 选择主课程视频。
2. 选择讲师视频或头像。
3. 查看素材状态。

优先级：P1。

说明：

第一版可以将素材入口放在左侧，也可以合并到顶部或属性面板，但必须让用户清楚知道主视频和讲师素材是否已配置。

### 4.4 中央实时预览区

用途：

1. 展示最终视频画面效果。
2. 支持点击模块选中。
3. 支持播放器控件用于预览和时间点配置。

优先级：P0。

编辑器中可出现：

1. 播放按钮。
2. 暂停按钮。
3. 拖动进度。
4. 当前时间显示。
5. 使用当前时间入口。

最终视频中不得出现以上控件。

### 4.5 右侧属性面板

用途：

1. 编辑当前选中模块。
2. 编辑阶段字段。
3. 编辑事件字段。
4. 编辑布局开关。

优先级：P0。

属性面板根据选中对象变化：

1. 课程信息。
2. 讲师区域。
3. 课程地图。
4. 任务追踪。
5. 重点提示。
6. 底部阶段条。
7. 时间轴事件。

### 4.6 底部时间轴配置区

用途：

1. 展示课程阶段。
2. 展示时间轴事件列表。
3. 显示当前视频时间。
4. 支持“使用当前时间”。
5. 支持点击阶段或事件跳转预览。

优先级：P0。

第一版形态：

1. 阶段表格。
2. 事件表格。
3. 简化时间轴视图。

不要求第一版做复杂拖拽轨道。

| 模块 | 位置 | 用途 | 优先级 | 是否随时间变化 |
| --- | --- | --- | --- | --- |
| 主课程视频 | 中央主体 | 承载课程内容 | P0 | 是，视频播放本身 |
| 顶部课程信息栏 | 顶部 | 建立课程上下文 | P0 | 默认否 |
| 右侧辅助栏 | 右侧 | 承载地图、任务、提示 | P0 | 内部模块是 |
| 课程地图 | 右侧上部 | 显示学习路径 | P0 | 是 |
| 任务追踪 | 右侧中部 | 显示当前任务 | P0 | 是 |
| 重点提示 | 右侧下部或安全弹层 | 强调关键内容 | P0 | 是 |
| 底部课程阶段条 | 底部 | 显示阶段导航 | P0 | 是 |
| 讲师小窗 | 左下或底部 HUD | 保留讲师存在感 | P1 | 视频内容是 |
| 底部状态 HUD | 底部 | 显示解锁、完成、行动状态 | P1 | 是 |

## 6. 第一版布局开放项

第一版允许用户配置：

1. 讲师小窗位置。
2. 讲师小窗显示或隐藏。
3. 右侧辅助栏显示模式。
4. 底部阶段条显示模式。
5. 顶部课程信息栏显示或隐藏。
6. 主视频适配方式。
7. 基础主题预设。

## 7. 第一版布局不开放项

第一版不允许用户配置：

1. 任意拖拽模块。
2. 任意缩放模块。
3. 任意修改模块层级。
4. 任意改变画面比例。
5. 自定义所有字体和装饰。
6. 多套复杂动画。
7. 自定义播放器控件，因为最终视频不是播放器。
