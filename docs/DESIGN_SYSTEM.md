# 视觉系统

## 1. 视觉方向

《视频课程套壳》的第一版视觉方向为：

> AI 战术课程 HUD：轻量科幻、RTS 指挥界面感、深色科技、蓝紫能量光、金属细边框、克制高级。

关键词：

1. 视频优先。
2. 深色科技。
3. 课程指挥界面。
4. 任务推进。
5. 低噪声 HUD。
6. 蓝紫能量光。
7. 金属细边框。
8. 克制动效。

禁止方向：

1. 重赛博朋克霓虹污染。
2. 游戏直播间 UI。
3. 普通播放器皮肤。
4. 花哨剪辑软件时间线。
5. 大面积玻璃拟态模糊遮挡主视频。
6. 过度装饰的机甲面板。

## 2. 设计原则

### 2.1 内容层级

视觉权重顺序：

1. 主课程视频。
2. 当前阶段和当前任务。
3. 重点提示。
4. 课程地图。
5. 课程标题和讲师信息。
6. 装饰性 HUD 线条。

### 2.2 克制科技感

科技感通过结构、边框、细线、状态色和轻量动效表达，不通过高饱和大面积渐变或频繁闪烁表达。

### 2.3 信息可读性

所有最终视频文本必须在深色背景上可读。正文不低于 22 px，关键标签不低于 18 px。编辑器 UI 文本可按桌面应用规范使用 12 至 16 px。

### 2.4 状态不能只靠颜色

完成、当前、未开始、警告、锁定等状态必须同时使用颜色、图形和文字或图标区分。

### 3.3 语义色

| Token | Hex | 用途 |
| --- | --- | --- |
| status.current | #4DA3FF | 当前阶段、当前任务 |
| status.completed | #35E6D4 | 已完成、已同步 |
| status.upcoming | #65708F | 未开始 |
| status.locked | #3B4259 | 锁定 |
| status.warning | #F6B84B | 警告、避坑 |
| status.danger | #FF5C7A | 严重风险 |
| status.success | #48E6A2 | 成功、通过检查 |

### 3.4 颜色使用比例

推荐比例：

1. 深色背景和面板：75%。
2. 主视频内容：由素材决定，不额外染色。
3. 蓝紫高亮：10% 以内。
4. 青色完成状态：5% 以内。
5. 警告色：仅在 warning、homework、校验错误中使用。

避免整屏被单一蓝紫覆盖。蓝紫是能量光，不是大面积底色。

## 4. 字体系统

### 4.1 推荐字体

最终视频 HUD：

1. 标题和状态标签：Orbitron、Rajdhani 或同类科技感标题字体。
2. 正文和中文内容：思源黑体、Noto Sans SC、Microsoft YaHei UI。
3. 数字、时间码和状态编号：JetBrains Mono 或 DIN 风格等宽字体。

编辑器 UI：

1. 中文界面：系统 UI 字体优先。
2. 时间码和表格数字：JetBrains Mono。

### 4.2 字号基准，最终视频

| Token | 尺寸 | 用途 |
| --- | --- | --- |
| video.title | 34-40 px | 课程标题 |
| video.subtitle | 24-28 px | 章节标题 |
| video.panelTitle | 22-26 px | 右侧模块标题 |
| video.body | 22-24 px | 提示正文 |
| video.label | 16-18 px | 标签、状态 |
| video.numeric | 18-22 px | 编号、时间码类信息 |

### 4.3 字号基准，编辑器

| Token | 尺寸 | 用途 |
| --- | --- | --- |
| editor.title | 18-20 px | 面板标题 |
| editor.body | 14-16 px | 正文、字段 |
| editor.label | 12-13 px | 标签 |
| editor.table | 12-14 px | 表格内容 |
| editor.timecode | 13-14 px | 时间码 |

### 4.4 排版规则

1. 字重以 400、500、600、700 为主。
2. 中文正文行高 1.35 至 1.5。
3. 最终视频中单行标签可以使用略紧凑字距，但正文不使用负字距。
4. 标题过长时先缩短副标题或使用短名，不无限缩小字号。

## 5. 间距与网格

### 5.1 基准间距

采用 4 px 基础单位：

| Token | 值 | 用途 |
| --- | --- | --- |
| space.1 | 4 px | 细小间距 |
| space.2 | 8 px | 标签间距 |
| space.3 | 12 px | 模块内间距 |
| space.4 | 16 px | 面板内边距 |
| space.6 | 24 px | 画面外边距 |
| space.8 | 32 px | 大区块间距 |

### 5.2 最终视频布局间距

1. 画面外安全边距：24 px。
2. HUD 模块间距：12 px。
3. 面板内边距：16 至 20 px。
4. 右侧栏内部模块间距：12 px。
5. 底部栏与主视频间距：12 px。

### 5.3 编辑器布局间距

1. 工具栏高度：56 至 64 px。
2. 左侧素材区宽度：240 至 280 px。
3. 右侧属性面板宽度：320 至 380 px。
4. 底部时间轴高度：220 至 280 px。
5. 面板内表单字段垂直间距：12 至 16 px。

## 6. 面板系统

### 6.1 面板底色

HUD 面板使用半透明深色，但透明度不得影响文字可读性。

推荐：

1. 最终视频面板：rgba(7, 12, 28, 0.82)。
2. 高层级提示面板：rgba(12, 18, 38, 0.92)。
3. 编辑器面板：#0B1020 或 #111827。

### 6.2 面板边框

1. 默认边框：1 px，border.subtle。
2. 当前状态边框：1 px，border.strong。
3. 警告边框：1 px，status.warning，局部使用。
4. 不使用厚重描边。

### 6.3 圆角

1. HUD 面板圆角：6 px。
2. 小标签圆角：4 px。
3. 编辑器卡片圆角：6 至 8 px。
4. 不使用大圆角胶囊风格作为主视觉。

### 6.4 金属细边框

金属感来自：

1. 低透明度亮边。
2. 角点短线。
3. 单侧高光线。
4. 极轻微内阴影。

禁止使用：

1. 大面积银色渐变。
2. 拟物金属按钮。
3. 高反光装饰。

## 7. 发光与阴影

### 7.1 发光规则

发光只用于当前状态、节点点亮、能力解锁和短时反馈。

推荐：

1. 当前节点：0 0 16 px energy.glow。
2. 能力解锁：0 0 20 px energy.purpleGlow。
3. 警告：0 0 14 px rgba(246, 184, 75, 0.22)。

### 7.2 禁止滥用

1. 不给所有面板同时加发光。
2. 不使用持续闪烁。
3. 不使用高饱和霓虹描边包围主视频。
4. 不让发光覆盖主视频细节。

## 8. 状态视觉规范

### 8.1 当前状态

用于当前阶段、当前任务、当前地图节点。

表现：

1. energy.blue 高亮。
2. 左侧或顶部短状态条。
3. 轻量发光。
4. 文案标记 `当前` 或 `ACTIVE`。

### 8.2 完成状态

用于已完成阶段、任务和地图节点。

表现：

1. energy.cyan 或 status.success。
2. 小型完成图标或勾形符号。
3. 连接线点亮。
4. 不使用大面积绿色填充。

### 8.3 未开始状态

表现：

1. text.muted。
2. border.subtle。
3. 低亮度节点。
4. 不显示发光。

### 8.4 锁定状态

表现：

1. status.locked。
2. 低透明度。
3. 锁定图标或短标签。
4. 不与未开始状态只靠颜色区分。

### 8.5 警告状态

表现：

1. status.warning 或 status.danger。
2. 左侧警告条。
3. 明确提示类型文字。
4. 不使用全屏红色闪烁。

## 9. 动效规范

### 9.1 最终视频 HUD 动效

推荐动效：

1. 提示入场：180 至 240 ms，opacity + translateY 8 px。
2. 提示退场：120 至 180 ms，opacity。
3. 节点点亮：240 至 320 ms，光圈扩散一次。
4. 任务切换：180 至 240 ms，旧任务淡出，新任务淡入。
5. 能力解锁：300 至 400 ms，短脉冲一次。

### 9.2 编辑器动效

推荐动效：

1. 面板切换：150 至 200 ms。
2. 选中框出现：100 至 150 ms。
3. 错误提示：150 至 200 ms。
4. 保存成功：短 toast 3 至 5 秒。

### 9.3 无障碍与克制

1. 支持 reduced motion 降低或关闭非必要动效。
2. 不使用无限循环装饰动画。
3. 不使用会影响主视频观看的扫描线闪烁。
4. 任何动效都应表达状态变化，而不是纯装饰。

## 10. 图标与线条

### 10.1 图标风格

1. 使用一致的线性图标。
2. 推荐 1.5 至 2 px 描边。
3. 图标尺寸：16、20、24 px。
4. 不使用 emoji 作为结构图标。

### 10.2 线条风格

1. 默认线条 1 px。
2. 连接线使用低透明度蓝灰。
3. 当前路径连接线使用 energy.cyan。
4. 装饰线条不得超过信息线条视觉权重。

## 11. 可读性约束

1. 最终视频正文对比度至少达到 WCAG AA 的实际可读水平。
2. 重点提示最多 2 至 3 行。
3. 阶段短名建议 2 至 6 个中文字符。
4. 任务标题建议 8 至 14 个中文字符。
5. 地图节点名称建议 2 至 8 个中文字符。
6. 超长内容在编辑器中提示用户缩短，而不是在成片中无限缩小。

## 12. 主题开放边界

第一版默认只需要一套主题：AI 战术课程 HUD。

可开放：

1. 主能量色，从蓝、紫、青中选择。
2. 品牌标识文字。
3. 轻量品牌色点缀。

不开放：

1. 完整自定义字体系统。
2. 任意修改所有颜色。
3. 多套复杂皮肤市场。
4. 自定义播放器皮肤。
