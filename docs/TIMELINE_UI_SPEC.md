# 时间轴联动 UI 规格

## 1. 核心定义

时间轴联动 UI 是《视频课程套壳》的核心体验。它让最终视频 HUD 随主课程视频时间变化，而不是停留在静态遮罩。

所有联动均以主课程视频时间为唯一基准。编辑器中的播放、暂停和拖动只用于配置和预览，不进入最终 MP4。

## 2. 时间轴配置区目标

底部时间轴配置区需要让用户完成：

1. 创建课程阶段。
2. 设置阶段开始和结束时间。
3. 添加时间轴事件。
4. 将事件绑定到 HUD 模块。
5. 使用当前视频时间写入时间字段。
6. 点击阶段或事件跳转预览。
7. 校验事件冲突和缺失信息。
8. 预览最终视频中对应时间点的 HUD 状态。

第一版不做复杂多轨剪辑时间线。推荐使用“阶段表 + 事件表 + 简化时间刻度”的组合。

## 3. 底部课程阶段条配置

### 3.1 编辑器配置方式

用户在底部时间轴配置区的阶段视图中配置 CourseStage：

| 字段 | 说明 |
| --- | --- |
| 阶段名称 | 完整阶段名称，用于属性面板和校验 |
| 短名称 | 最终视频阶段条显示，建议 2-6 个中文字符 |
| 开始时间 | 阶段开始时间 |
| 结束时间 | 阶段结束时间，可由下一阶段开始推算 |
| 关联地图节点 | 进入阶段时点亮的地图节点 |
| 默认任务 | 进入阶段时自动切换的任务 |
| 默认重点提示 | 进入阶段时可展示的提示 |

操作：

1. 点击“新增阶段”创建阶段。
2. 播放或拖动主视频到目标时间。
3. 点击“使用当前时间”写入开始时间或结束时间。
4. 点击阶段行，中央预览跳转到阶段开始时间。
5. 点击预览画面中的 CourseStageBar，右侧面板显示该阶段配置。

### 3.2 最终视频表现

最终视频中 CourseStageBar：

1. 已完成阶段显示 completed。
2. 当前阶段显示 current。
3. 未开始阶段显示 upcoming。
4. 阶段之间显示轻量连接线。
5. 不显示播放头、拖动滑块、当前播放时间或总时长。
6. 不可点击。

### 3.3 状态推算规则

给定当前播放时间 currentTime：

1. currentTime 小于 stage.startTime：阶段为未开始。
2. currentTime 位于 stage.startTime 与 stage.endTime 之间：阶段为当前。
3. currentTime 大于 stage.endTime：阶段为已完成。
4. 若 endTime 缺失，则用下一阶段 startTime 推算。

## 4. 地图节点点亮配置

### 4.1 编辑器配置方式

地图节点可通过两种方式点亮：

1. 阶段默认联动：CourseStage.mapNodeId。
2. 手动事件：map_node_activate。

map_node_activate 事件字段：

| 字段 | 说明 |
| --- | --- |
| 触发时间 | 节点点亮时间 |
| 目标模块 | course_map |
| 节点 | 目标 MapNode |
| 状态 | current、completed、unlocked |
| 标题 | 可选，用于事件列表 |
| 优先级 | 冲突时排序 |

编辑器操作：

1. 点击预览画面中的 ChapterMap。
2. 在右侧面板编辑节点列表。
3. 为节点绑定阶段或独立点亮时间。
4. 点击地图节点，预览跳转到绑定时间。

### 4.2 最终视频表现

1. 当前节点出现蓝色能量边框。
2. 已完成节点显示青色完成标记。
3. 未开始节点低亮。
4. 锁定节点显示低透明度和锁定标记。
5. 节点点亮可有一次性光圈扩散，禁止持续闪烁。

## 5. 任务状态变化配置

### 5.1 编辑器配置方式

任务状态可通过两种方式变化：

1. 阶段默认任务：CourseStage.defaultTaskId。
2. 手动事件：task_update。

task_update 事件字段：

| 字段 | 说明 |
| --- | --- |
| 触发时间 | 任务切换时间 |
| 目标模块 | task_tracker |
| 任务 | 目标 TaskItem |
| 状态 | not_started、current、completed |
| 自动完成上一任务 | 默认开启 |
| 标题 | 事件标题 |
| 优先级 | 冲突排序 |

编辑器操作：

1. 点击 TaskTracker 打开任务列表。
2. 新增任务并绑定阶段。
3. 在事件表添加 task_update。
4. 使用当前时间写入触发时间。
5. 点击事件行跳转预览任务切换后的画面。

### 5.2 最终视频表现

1. 当前任务高亮。
2. 已完成任务显示完成标记。
3. 下一任务低亮显示。
4. 任务切换使用短淡入淡出，不使用夸张转场。
5. 同一时间只允许一个 current 任务。

## 6. 重点提示弹出配置

### 6.1 编辑器配置方式

重点提示由 hint_show 事件控制，也可由 stage_summary 和 homework_reminder 复用 WarningPanel。

事件字段：

| 字段 | 说明 |
| --- | --- |
| 触发时间 | 提示出现时间 |
| 结束时间 | 提示消失时间 |
| 持续时间 | 可由结束时间推算 |
| 提示类型 | 重点、新手重点、警告、阶段总结、作业提醒 |
| 标题 | 最终视频显示标题 |
| 正文 | 最终视频显示正文 |
| 目标模块 | warning_panel |
| 优先级 | 同时冲突时使用 |

编辑器操作：

1. 点击 WarningPanel。
2. 在右侧面板编辑标题、正文、类型和持续时间。
3. 点击“使用当前时间”写入开始或结束时间。
4. 预览提示出现和消失。
5. 若正文过长，编辑器显示长度提示。

### 6.2 最终视频表现

1. 提示以右侧 WarningPanel 为主。
2. 入场使用 180 至 240 ms 淡入和轻位移。
3. 消失使用 120 至 180 ms 淡出。
4. 警告类使用琥珀色边条或图标。
5. 作业类可同步到底部状态 HUD。
6. 不遮挡主视频核心内容。

### 6.3 阅读时间建议

| 文案长度 | 最短持续时间 |
| --- | --- |
| 12 字以内 | 4 秒 |
| 13-24 字 | 6 秒 |
| 25-40 字 | 8 秒 |
| 超过 40 字 | 编辑器提示缩短 |

## 7. 能力点解锁配置

### 7.1 编辑器配置方式

能力点解锁由 skill_unlock 事件控制。

字段：

| 字段 | 说明 |
| --- | --- |
| 触发时间 | 解锁出现时间 |
| 能力点名称 | 显示标题 |
| 能力点说明 | 可选短正文 |
| 目标模块 | bottom_status_hud，可联动 course_map |
| 关联节点 | 可选 MapNode |
| 持续时间 | 建议 3-5 秒 |

编辑器操作：

1. 在事件表新增 skill_unlock。
2. 填写能力点名称。
3. 选择是否点亮地图节点。
4. 使用当前时间写入触发时间。
5. 预览底部状态 HUD 的解锁反馈。

### 7.2 最终视频表现

1. BottomStatusHud 显示能力点解锁短提示。
2. 可同步 ChapterMap 节点进入 unlocked 或 completed。
3. 使用紫色能量光一次性脉冲。
4. 不播放长动画，不遮挡主视频。

## 8. 阶段总结配置

### 8.1 编辑器配置方式

阶段总结由 stage_summary 事件控制。

字段：

| 字段 | 说明 |
| --- | --- |
| 触发时间 | 通常在阶段结束前或结束时 |
| 关联阶段 | 对应 CourseStage |
| 标题 | 例如“阶段完成” |
| 正文 | 总结该阶段完成内容 |
| 目标模块 | warning_panel，可同步 bottom_status_hud |
| 持续时间 | 建议 5-8 秒 |

编辑器操作：

1. 选中阶段。
2. 点击“添加阶段总结”。
3. 默认触发时间可设为阶段结束前 5 秒。
4. 用户可用当前时间覆盖默认时间。

### 8.2 最终视频表现

1. WarningPanel 显示总结标题和短正文。
2. BottomStatusHud 可显示 `阶段完成` 短状态。
3. CourseStageBar 在下一阶段开始时更新状态。
4. 不与下一阶段开场提示同时抢占。

## 9. 作业提醒配置

### 9.1 编辑器配置方式

作业提醒由 homework_reminder 事件控制。

字段：

| 字段 | 说明 |
| --- | --- |
| 触发时间 | 通常在课程末尾或阶段末尾 |
| 标题 | 作业或行动标题 |
| 正文 | 行动说明 |
| 目标模块 | warning_panel、bottom_status_hud |
| 是否切换任务 | 可选，将 TaskTracker 切到课后行动 |
| 持续时间 | 建议 6-10 秒 |

编辑器操作：

1. 在事件表新增 homework_reminder。
2. 填写作业标题和行动说明。
3. 选择是否同步为当前任务。
4. 预览课程末尾状态。

### 9.2 最终视频表现

1. WarningPanel 显示作业详情。
2. BottomStatusHud 显示一句行动提示。
3. TaskTracker 可切换到课后行动任务。
4. 不显示提交按钮、打卡入口或平台交互能力。

## 10. 编辑器预览联动

### 10.1 时间跳转

以下操作会改变预览当前时间：

1. 点击阶段行。
2. 点击事件行。
3. 点击地图节点。
4. 点击底部阶段条中的阶段，编辑器专用。
5. 拖动编辑器预览进度条。

### 10.2 状态重算

每次 currentTime 改变时，编辑器应重新计算：

1. 当前阶段。
2. 地图节点状态。
3. 当前任务。
4. 当前提示。
5. 底部状态 HUD。
6. 模块显示隐藏状态。

### 10.3 选中事件预览

选中事件后：

1. 预览跳转到事件触发时间。
2. 目标模块显示事件生效后的状态。
3. 右侧属性面板显示该事件字段。
4. 底部事件行进入选中态。

## 11. 冲突与校验 UI

编辑器需要提示以下问题：

1. 阶段开始时间晚于结束时间。
2. 阶段时间重叠。
3. 提示类事件缺少结束时间或持续时间。
4. 同一时间同一模块存在多个同优先级事件。
5. 任务列表中同时存在多个 current 任务。
6. 阶段条阶段数量超过标准模式可读范围。
7. 提示正文过长。
8. 主视频未导入。

校验提示位置：

1. 字段级错误显示在右侧属性面板。
2. 时间冲突显示在底部时间轴行内。
3. 渲染阻断项显示在渲染前检查清单。

## 12. 渲染时表现规则

Remotion 渲染时应按主视频时间逐帧或逐采样点计算 HUD 状态：

1. 先根据 CourseStage 推算默认状态。
2. 再应用 TimelineEvent。
3. 手动事件覆盖默认联动。
4. 同模块冲突按 priority 处理。
5. 提示类事件按 startTime 和 endTime 显示或隐藏。
6. 最终 MP4 只包含视觉结果，不包含可交互时间轴数据。
