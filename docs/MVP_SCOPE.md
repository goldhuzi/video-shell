# MVP 范围冻结

## 1. 第一版目标

第一版目标是验证：个人课程创作者能否通过可视化编辑器，手动配置时间轴事件，并稳定生成一条带游戏化课程 HUD 的 16:9 课程视频。

第一版不追求复杂剪辑能力，也不追求完全自由设计。核心必须打通：

1. 导入主课程视频。
2. 配置课程基础信息。
3. 配置固定布局下的 HUD 模块。
4. 手动设置课程阶段和时间点。
5. 配置时间轴事件。
6. 在编辑器中预览随时间变化的界面状态。
7. 渲染导出最终 MP4。

## 2. 第一版必须做什么

### 2.1 主视频导入与预览

1. 支持导入主课程视频。
2. 支持在编辑器中播放、暂停、拖动预览，用于配置时间点。
3. 支持显示当前播放时间。
4. 支持“使用当前时间”写入阶段或事件时间点。
5. 主视频在最终画面中保持最高优先级，默认完整显示，不裁切关键内容。

### 2.2 课程基础信息配置

1. 课程标题。
2. 章节标题或副标题。
3. 讲师名称。
4. 讲师身份标签。
5. 课程编号或课程序号。
6. 可选品牌或主题预设。

### 2.3 讲师小窗或头像

1. 支持讲师小窗视频或头像二选一。
2. 支持隐藏讲师小窗。
3. 支持有限位置预设：
   - 左下角。
   - 右下角。
   - 底部 HUD 内。
4. 默认建议放在左下角或底部 HUD 内，避免遮挡主课程内容。

### 2.4 固定 HUD 布局

第一版必须提供一个稳定的 16:9 最终视频布局，至少包含：

1. 主视频区域。
2. 顶部课程信息栏。
3. 右侧辅助栏。
4. 课程地图。
5. 任务追踪。
6. 重点提示。
7. 讲师小窗或头像。
8. 底部课程阶段条。
9. 底部状态 HUD。

### 2.5 时间轴事件配置

第一版必须支持手动配置以下事件：

1. 地图节点点亮。
2. 重点提示弹出或切换。
3. 任务状态变化。
4. 底部课程阶段条变化。
5. 能力点解锁。
6. 阶段总结。
7. 作业或行动提醒。

每个事件至少需要包含：

1. 事件类型。
2. 触发时间。
3. 事件标题或名称。
4. 事件正文或显示文案。
5. 目标模块。
6. 持续时间或结束时间，适用于提示类事件。

### 2.6 课程阶段条

1. 底部必须支持课程阶段条。
2. 阶段条用于学习导航，不是播放器进度条。
3. 阶段条展示：
   - 已完成阶段。
   - 当前阶段。
   - 未开始阶段。
4. 阶段条在编辑器中可以点击跳转到对应时间。
5. 阶段条在最终 MP4 中不可点击，只作为视觉提示。
6. 阶段条需要与右侧课程地图、任务追踪产生基础联动。

### 2.7 可视化编辑器

第一版不应只靠手写 JSON。编辑器必须包含：

1. 顶部工具栏。
2. 素材选择入口。
3. 中央课程画面实时预览。
4. 右侧属性面板。
5. 底部时间轴配置区。
6. 渲染与导出入口。

用户应该能：

1. 在预览画面中点击模块并在右侧面板编辑。
2. 点击顶部栏编辑课程标题。
3. 点击讲师区域编辑讲师信息。
4. 点击右侧任务追踪编辑任务。
5. 点击课程地图编辑节点。
6. 点击底部阶段条编辑阶段名称和时间点。
7. 修改内容后在预览画面中即时看到结果。

### 2.8 预览与渲染

1. 支持编辑器内实时或准实时预览。
2. 支持预览某个时间点的 HUD 状态。
3. 支持渲染最终 16:9 MP4。
4. 最终视频中不出现播放、暂停、拖动、倍速、音量、全屏等播放器控件。

## 3. 第一版不做什么

### 3.1 不做普通剪辑能力

第一版不做：

1. 多轨视频剪辑。
2. 复杂转场。
3. 音频混音。
4. 字幕逐字校对。
5. 素材拼接工作流。
6. 调色、降噪、美颜等专业后期功能。

### 3.2 不做课程平台能力

第一版不做：

1. 学员账号。
2. 课程售卖。
3. 支付。
4. 作业提交。
5. 学习进度记录。
6. 课程评论或社群。

### 3.3 不做播放器产品

第一版不做：

1. 网页播放器。
2. 可点击章节跳转的最终播放体验。
3. 互动问答。
4. 弹幕。
5. 播放器皮肤。

编辑器里可以有播放器控件，因为它用于配置时间点；最终导出视频中不能出现播放器控件。

### 3.4 不做自由设计软件

第一版不做：

1. 任意拖拽所有模块。
2. 任意缩放所有模块。
3. 任意图层排序。
4. 自定义所有字体、阴影、动效和形状。
5. 类似 Figma 的自由画布编辑。

### 3.5 不做 AI 自动识别

第一版不做：

1. 自动识别章节。
2. 自动提取重点。
3. 自动生成任务。
4. 自动生成地图节点。
5. 自动推荐时间点。

所有关键时间点第一版由用户手动配置。

## 4. 功能优先级

## P0：必须完成，否则产品不成立

1. 主视频导入与预览。
2. 16:9 固定最终视频布局。
3. 顶部课程信息栏。
4. 右侧辅助栏。
5. 课程地图节点展示与点亮。
6. 任务追踪展示与状态切换。
7. 重点提示展示与切换。
8. 底部课程阶段条。
9. 手动配置阶段开始时间。
10. 手动配置时间轴事件。
11. 编辑器内播放器控件和当前时间读取。
12. “使用当前时间”写入时间点。
13. 可视化预览。
14. 右侧属性面板。
15. 表格式或列表式时间轴配置区。
16. 渲染导出 MP4。
17. 最终 MP4 不出现播放器控件。
18. 主视频内容优先，不被 HUD 关键遮挡。

## P1：第一版建议完成，影响体验但不阻断核心验证

1. 讲师小窗视频或头像。
2. 讲师小窗位置预设。
3. 右侧辅助栏显示模式。
4. 底部阶段条标准模式与紧凑模式。
5. 能力点解锁事件。
6. 阶段总结事件。
7. 作业提醒事件。
8. 事件持续时间配置。
9. 点击阶段条或地图节点跳转预览时间。
10. 基础主题预设。
11. 项目配置保存与再次编辑。
12. 渲染前检查清单。

## P2：后续版本考虑

1. AI 自动章节识别。
2. AI 自动生成重点提示。
3. AI 自动生成任务和地图节点。
4. 自定义网页播放器。
5. 最终网页播放器中的可点击章节跳转。
6. 多套 HUD 模板市场。
7. 更自由的布局拖拽。
8. 批量渲染多节课。
9. 多语言课程包装。
10. 字幕自动生成与校对。
11. 音频增强。
12. 团队协作和评论。
13. 课程平台集成。
14. 云端渲染队列。

## 5. MVP 成功标准

### 5.1 用户成功标准

用户无需写 JSON，即可完成：

1. 导入一条课程视频。
2. 配置至少 5 个课程阶段。
3. 配置至少 7 个时间轴事件。
4. 在预览中确认 HUD 随时间变化。
5. 导出一条无播放器控件的 16:9 MP4。

### 5.2 产品成功标准

1. 输出视频能清晰表达课程所处阶段。
2. 学员能通过画面判断当前任务和重点。
3. HUD 不遮挡主视频核心内容。
4. 底部阶段条被理解为学习导航，而不是播放器进度条。
5. 用户能复用同一布局制作下一节课程。
